What Is a Category?

§1 — Why arrows?

The same shape, over and over

Walk through any corner of mathematics and you keep meeting the same arrangement: a kind of thing, paired with a kind of structure-preserving map between those things.

Sets come with functions. Groups come with homomorphisms. Vector spaces come with linear maps. Topological spaces come with continuous functions. Data types come with programs. In every one of these worlds the maps compose — do one, then another — composition is associative, and every object has a do-nothing map that changes nothing.

Category theory takes that recurring shape and makes it the object of study. The move is deliberately austere: to understand an object, don't open it up and inspect its elements — look instead at the arrows going into and out of it. It sounds like throwing away information. It isn't. We'll soon be able to pin down ideas like isomorphism, product, and even the empty set using nothing but arrows and how they compose.

Two ways through this course

Everything here can be done with pencil and paper. Each lesson is complete as mathematics: definitions, examples, proofs, and exercises to work by hand. Alongside runs an optional Python track — dark panels marked Optional · Python that open when you click them (the switch at the top of the page opens or closes all of them at once). The labs re-check the lesson’s claims by machine, and nothing outside them depends on them. If you have never written a line of code, skip every one and you will miss no mathematics. If you enjoy code, open them: watching a law fail an assertion is a memorable way to learn what the law says.

§2 — The definition

A category is four pieces of data and two laws

Here it is in full. It is short. Resist the urge to find it underwhelming — its shortness is exactly what lets it apply everywhere.

Definition · Category

A category 𝒞 consists of:

  • a collection of objects — A, B, C, …
  • for each pair of objects X, Y, a collection of morphisms (arrows) from X to Y, written 𝒞(X, Y); an arrow is written f : X → Y
  • for every object X, an identity arrow idX : X → X
  • a composition rule: given f : X → Y and g : Y → Z, an arrow g ∘ f : X → Z

subject to two laws:

Associativityh ∘ (g ∘ f) = (h ∘ g) ∘ f
IdentityidY ∘ f = f = f ∘ idX

Three things to internalize right away.

Composition reads right-to-left. The expression g ∘ f means “first f, then g,” matching how g(f(x)) works. The arrow on the right goes first.

Arrows are typed. You can only compose g ∘ f when the target of f is the source of g. Most pairs of arrows simply cannot be composed, and that’s the point — the bookkeeping of sources and targets is doing real work.

That is the entire toolkit. Objects, typed arrows, who-composes-with-whom, and which arrows are identities. There is no notion of an element, no “inside” of an object. Whatever we want to say, we must say with arrows.

A small honest footnote

Why “collection” rather than “set”? Because the category of all sets has too many objects to itself be a set — assuming otherwise revives Russell’s paradox. When every 𝒞(X, Y) is a genuine set we call 𝒞 locally small; if the objects form a set too, small. You can safely file this away for now; it changes none of the reasoning below.

§3 — Diagrams & commuting

How category theorists write equations: they draw them

A diagram is just a picture of some objects and some arrows between them. A diagram commutes when any two directed paths sharing the same start and the same end compose to the same arrow. Commutativity is an equation — drawn rather than written.

§4 — A gallery of categories

Nine examples that stretch the definition in every direction

The definition is abstract on purpose. The only cure for “but what is a category, really?” is to meet enough of them that the pattern, not any one instance, becomes the thing you see.

i. Set — the prototype

Objects are sets; an arrow X → Y is a function from X to Y; composition is ordinary function composition; idX is the function that returns its input. The laws hold for the most pedestrian reasons: composing functions is associative, and sandwiching with the identity function changes nothing. Keep Set in your pocket as the example to sanity-check every new idea against.

ii. A preorder is a category

Take any set with a relation ≤ that is reflexive and transitive. Build a category: the objects are the elements, and you draw exactly one arrow x → y whenever x ≤ y (and none otherwise). Reflexivity (x ≤ x) hands you every identity; transitivity (x ≤ y ≤ z ⟹ x ≤ z) hands you composition. The two laws come for free, because between any two objects there is at most one arrow, so any two arrows with matching ends are automatically equal.

iii. A monoid is a one-object category

A monoid is a set M with an associative operation and a unit e. Make a category with a single object •, let the arrows • → • be the elements of M, let composition be the monoid’s operation, and let id• = e. The category axioms become, line for line, the monoid axioms. Run it backwards and the same is true: any category with one object is a monoid.

iv. Tiny categories you can draw in full

Call 𝟙 the category with one object and nothing but its identity. Call 𝟚 the category with two objects and a single non-identity arrow 0 → 1. These look like toys, but they earn their keep: a structure-preserving map out of 𝟚 into some category 𝒞 is exactly a choice of one arrow in 𝒞. Small categories are the “shapes” you probe other categories with.

v. Types and programs

In a typed programming language, take the types as objects and (pure, total) functions as arrows; composition is function composition and the identity is the function that returns its argument unchanged. This is the category programmers already work inside without naming it — which is exactly why this course can offer an optional Python track: for a programmer, much of what follows is less translation than recognition.

vi. Rel — arrows that are not functions

Keep sets as the objects but let an arrow X → Y be a relation from X to Y: any subset R ⊆ X × Y, with x R y read “x is related to y.” Relations compose by chaining through a middle element:

S ∘ R = { (x, z) : there is some y with x R y and y S z },

and the identity on X is the equality relation { (x, x) : x ∈ X }. Associativity holds because both bracketings of T ∘ S ∘ R unwind to the same statement — “there are y and z with x R y, y S z, and z T w” — and composing with equality changes nothing. Every function is a relation (its graph), so Set sits inside Rel: same objects, fewer arrows. But a general arrow of Rel may relate one x to several y’s, or to none. Nothing in the definition of a category asked arrows to be functions, and here they are not.

vii. Mat — where composition is matrix multiplication

Take the natural numbers 0, 1, 2, … as objects, and let an arrow n → m be an m × n matrix of real numbers (so a 3 × 2 matrix is an arrow 2 → 3). Composition is matrix multiplication: for A : n → m and B : m → p, the composite B ∘ A is the product BA, a p × n matrix. The identity on n is the n × n identity matrix. Here “arrows are typed” is a fact you already know under another name: the product BA exists exactly when the shapes match, and the category laws are the associativity of matrix multiplication and IA = A = AI. Notice that the objects of Mat have no elements whatsoever — the object 3 is just the number three. (The object 0 is included: there is exactly one “empty” matrix n → 0 and one 0 → n for each n.)

viii. The big categories of mathematics

The examples that motivated the subject follow one template — sets with structure, functions that preserve it — and each is a category for the same reason Set is: a composite of structure-preserving functions preserves structure, and so does the identity function.

Notice the two levels on which a monoid can now appear: a single monoid is a category (example iii), and all monoids together form one (Mon). Both viewpoints will be used.

ix. The smallest categories of all

Any set S becomes a discrete category: the objects are the elements of S and the only arrows are the identities. There is nothing to compose, so the laws hold with no work — a set is a category with no interesting arrows. The extreme case is the empty category 𝟘, with no objects and no arrows; every requirement in the definition begins “for every object” or “for every arrow,” so all of them hold vacuously. Discrete categories and one-object categories are the two ends of a spectrum: all objects and no arrows, or one object and all arrows. A general category mixes the two.

§5 — Isomorphisms

When two objects are the same for every arrows-only purpose

The first payoff of the arrows-only discipline is a definition of sameness that never mentions an element.

Definition · Isomorphism

An arrow f : X → Y is an isomorphism if there is an arrow g : Y → X with

g ∘ f = idX   and   f ∘ g = idY.

Such a g is an inverse of f. When an inverse exists it is unique (Exercise 10), and is written f−1. Two objects are isomorphic, written X ≅ Y, when some isomorphism runs between them.

What an isomorphism is depends on the category, and the gallery of §4 gives the tour.

  • In Set the isomorphisms are exactly the bijections: a function has a two-sided inverse precisely when it is one-to-one and onto. So two finite sets are isomorphic exactly when they have the same number of elements — {1, 2, 3} ≅ {a, b, c} — and nothing about what the elements are survives.
  • In a preorder, x ≅ y means x ≤ y and y ≤ x. In a partial order that forces x = y; in a general preorder it does not. Order the integers by divisibility: 3 divides −3 and −3 divides 3, so 3 ≅ −3 although 3 ≠ −3.
  • In a monoid viewed as a one-object category, the isomorphisms are the invertible elements. In the monoid of integers under multiplication these are 1 and −1; in (ℤ/3, +) every element is invertible, which is what makes it a group.
  • In Mat an arrow is an isomorphism exactly when the matrix is invertible. Invertible matrices are square, so in Mat two different objects are never isomorphic.
  • In Grp, Vect and Top the isomorphisms are the group isomorphisms, the invertible linear maps, and the homeomorphisms.
Careful · Isomorphism is not “bijective arrow”

In Grp and Vect, a homomorphism that happens to be a bijection always has a homomorphism for its inverse. In Pos and Top that fails. Take the two-element set {a, b} twice: once with no order relation between a and b, once with a ≤ b. The identity function from the first to the second is monotone and bijective, but its inverse is not monotone — so it is not an isomorphism in Pos. The arrow-theoretic definition gets every case right for one reason: it demands an inverse in the category.

Three facts, each a short exercise in arrow-pushing (Exercise 10), make ≅ behave like equality: every identity is an isomorphism; the inverse of an isomorphism is an isomorphism; a composite of isomorphisms is an isomorphism. Together they say:

Proposition · Isomorphism is an equivalence relation

In any category: X ≅ X; if X ≅ Y then Y ≅ X; and if X ≅ Y and Y ≅ Z then X ≅ Z.

Proof. The identity idX is its own inverse, giving X ≅ X. If f : X → Y has inverse g, then the two defining equations, read with the roles of f and g exchanged, say that g : Y → X has inverse f. And if f : X → Y and f′ : Y → Z are isomorphisms, then f′ ∘ f has inverse f−1 ∘ f′−1 by Exercise 10(c). ∎

Isomorphic objects have the same arrows

Here is the reason category theory treats isomorphic objects as interchangeable. Suppose f : X → Y is an isomorphism, and let W be any object at all. Then composing with f converts arrows into X to arrows into Y,

(h : W → X)  ↦  (f ∘ h : W → Y),

and this conversion is a bijection: its inverse is k ↦ f−1 ∘ k, since f−1 ∘ (f ∘ h) = (f−1 ∘ f) ∘ h = h and f ∘ (f−1 ∘ k) = k. The same works for arrows out of X and Y, composing on the other side. So X and Y have, in a precise sense, the same arrows to and from every other object, and anything you can say about X in the language of arrows can be translated along f into a statement about Y. A property is called categorical when isomorphic objects always share it. “Has exactly three elements” is a categorical property of a set; “contains the number 7” is not, and category theory will never ask.

Lesson 9 turns this observation around into a theorem, the Yoneda lemma: an object is determined up to isomorphism by its arrows.

Symmetries

An arrow X → X is an endomorphism of X, and an isomorphism X → X is an automorphism. The automorphisms of an object can always be composed with one another, composition is associative, idX is a unit, and each has an inverse: they form a group, written Aut(X). In Set, the automorphisms of {1, 2, 3} are its 3! = 6 permutations. Groups are what the symmetries of an object look like, in any category whatever — which is one reason the one-object categories of example (iii) deserve their place in the gallery. A category in which every arrow is an isomorphism is called a groupoid; a group is exactly a groupoid with one object (Exercise 8).

§6 — Finite categories by hand

Make the laws concrete: write the whole category down

A category with finitely many arrows is a finite amount of information, and all of it fits on one sheet of paper. List the objects; list the arrows with their sources and targets; then fill in a composition table recording g ∘ f for every composable pair. Once that is done the two laws stop being abstractions. They are finitely many equations, and you can check every one.

First table: the chain 𝟛

Build a category from the chain 0 ≤ 1 ≤ 2 as in example (ii): one arrow for each true inequality. That gives three identities i0, i1, i2, the arrows a : 0 → 1 and b : 1 → 2, and — because 0 ≤ 2 as well — an arrow c : 0 → 2. Six arrows in all. In the table below, the entry in row g and column f is g ∘ f, and a dash marks a pair that cannot be composed because the target of f is not the source of g.

The category 𝟛, complete: ten composable pairs out of thirty-six.

Only one entry carries real information: b ∘ a = c. Every other entry involves an identity, and the identity law dictates it. Now check the definition against the table, one requirement at a time.

  1. Typing. Each entry g ∘ f must run from the source of f to the target of g. For the interesting entry: a : 0 → 1 and b : 1 → 2, and the table gives c : 0 → 2. Correct.
  2. Identity law. The row of an identity, and the column of an identity, must copy the other arrow unchanged — i1 ∘ a = a, b ∘ i1 = b, and so on. Scan the table: every identity row and column does exactly that.
  3. Associativity. For every composable triple, h ∘ (g ∘ f) must equal (h ∘ g) ∘ f. If one of the three arrows is an identity the equation follows from the identity law, so only triples of non-identity arrows need attention — and 𝟛 has none, since three steps up a chain need four objects.

So 𝟛 is a category, verified completely by hand. The reasoning in step 3 can be made even shorter. In a category built from a preorder there is at most one arrow between any two objects, so two arrows with the same source and target are automatically equal — and h ∘ (g ∘ f) and (h ∘ g) ∘ f always have the same source and target. Such categories are called thin, and in a thin category associativity never needs checking.

Second table: a monoid

The monoid (ℤ/3, +) of example (iii) is a category with one object ∗ and three arrows 0, 1, 2 : ∗ → ∗. Now every pair is composable, and the composition table is just the addition table modulo 3:

g ∘ f012
0012
1120
2201

The identity arrow is 0, and its row and column copy the headings: that is the identity law. This category is as far from thin as possible, so associativity is a real claim about 3 × 3 × 3 = 27 triples. One of them, to see what a check looks like: (1 ∘ 2) ∘ 2 = 0 ∘ 2 = 2 and 1 ∘ (2 ∘ 2) = 1 ∘ 1 = 2. Checking all twenty-seven by hand is possible but dull; the efficient argument is that addition of integers is associative and reducing modulo 3 respects sums. Either way, the law is a finite, checkable statement.

Third table: a failure

It is worth seeing a table that fails. Keep one object, with arrows e, a, b, and try the table

g ∘ feab
eeab
aabb
bbaa

Typing is fine (there is only one object), and e obeys the identity law: its row and column copy the headings. But compare the two bracketings of a, a, b:

(a ∘ a) ∘ b = b ∘ b = a,    while    a ∘ (a ∘ b) = a ∘ b = b.

Associativity fails, so this table does not describe a category. The moral is that associativity is a genuine constraint: most ways of filling in a table violate it. (In this table every one of the eight triples of non-identity arrows fails; the optional lab below confirms the count.)

Optional · PythonFinite categories, checked by machine

Abstraction earns trust faster when you can poke it. First, inside Set, functions really are morphisms: store each function as a dictionary, build composites with one small helper, and test the identity and associativity laws on an actual example.

set_as_category.py — morphisms are functions
def compose(g, f):
    "g after f, for functions stored as dictionaries"
    return {x: g[f[x]] for x in f}

A = {1, 2, 3}
f = {1: 'a', 2: 'b', 3: 'a'}     # f : A -> B,  B = {'a', 'b'}
g = {'a': 'yes', 'b': 'no'}      # g : B -> C,  C = {'yes', 'no'}
h = {'yes': 1, 'no': 0}          # h : C -> D,  D = {0, 1}
id_A = {x: x for x in A}
id_B = {y: y for y in 'ab'}

print(compose(g, f))             # the composite g . f : A -> C

# identity law, on both sides
assert compose(f, id_A) == f == compose(id_B, f)
# associativity:  h . (g . f)  ==  (h . g) . f
assert compose(h, compose(g, f)) == compose(compose(h, g), f)
print("laws ok")
output{1: 'yes', 2: 'no', 3: 'yes'} laws ok

That checks one example in an infinite category. To do better, package the definition itself as data — objects, a typed list of arrows, a composition table, and a chosen identity per object — and write one function that verifies all four requirements at once. For a finite category, this is not a spot-check: it’s a complete proof, because the laws are quantified over a finite set of arrows.

finite_category.py — a law-checker
from itertools import product

class FiniteCategory:
    """objects, arrows (name -> (dom, cod)), a composition table,
       and a chosen identity arrow for each object."""
    def __init__(self, objects, arrows, comp, ident):
        self.obj, self.ar, self.comp, self.id = set(objects), arrows, comp, ident

    def dom(self, a): return self.ar[a][0]
    def cod(self, a): return self.ar[a][1]
    def composable(self, g, f): return self.dom(g) == self.cod(f)

    def check(self):
        for X in self.obj:                              # identities typed X -> X
            assert self.ar[self.id[X]] == (X, X)
        for g, f in product(self.ar, repeat=2):         # composition total & typed
            if self.composable(g, f):
                gf = self.comp[(g, f)]
                assert self.ar[gf] == (self.dom(f), self.cod(g))
        for f in self.ar:                               # unit laws
            X, Y = self.ar[f]
            assert self.comp[(self.id[Y], f)] == f
            assert self.comp[(f, self.id[X])] == f
        for h, g, f in product(self.ar, repeat=3):      # associativity
            if self.composable(h, g) and self.composable(g, f):
                assert self.comp[(h, self.comp[(g, f)])] == \
                       self.comp[(self.comp[(h, g)], f)]
        return True

# A monoid as a ONE-object category: integers mod 3 under addition.
arrows = {n: ('*', '*') for n in range(3)}            # the arrows ARE the elements
comp   = {(a, b): (a + b) % 3 for a in range(3) for b in range(3)}
Z3 = FiniteCategory({'*'}, arrows, comp, ident={'*': 0})
print(Z3.check())
outputTrue

Going deeper

Special arrows: monomorphisms, epimorphisms, and one-sided inverses

In Set the injective and surjective functions play starring roles — but “injective” and “surjective” are defined by talking about elements, which this course has forsworn. The arrows-only surrogates are cancellation properties, and they will follow us through the whole course (equalizers produce them in Lesson 7; right adjoints preserve them in Lesson 8).

Definition · Mono & epi

An arrow m : X → Y is a monomorphism (monic) if it is left-cancellable: m ∘ h = m ∘ k implies h = k, for every pair of arrows h, k : W → X. Dually, e : X → Y is an epimorphism (epic) if it is right-cancellable: h ∘ e = k ∘ e implies h = k, for every pair h, k : Y → Z.

The definitions are designed so that the following is true — and the proof shows why they are the right translation.

Theorem · In Set: monic = injective, epic = surjective

A function is a monomorphism in Set exactly when it is injective, and an epimorphism exactly when it is surjective.

Proof. Injective implies monic. Let m be injective and m ∘ h = m ∘ k. For each w we have m(h(w)) = m(k(w)), hence h(w) = k(w); so h = k.

Monic implies injective. Let m : X → Y be monic and suppose m(x) = m(x′). Let W = {∗} be a one-element set and let h, k : W → X be the functions sending ∗ to x and to x′. Then m ∘ h = m ∘ k, so h = k, which says x = x′.

Surjective implies epic. Let e : X → Y be surjective and h ∘ e = k ∘ e. Every y is e(x) for some x, so h(y) = h(e(x)) = k(e(x)) = k(y); so h = k.

Epic implies surjective. Let e : X → Y be epic, and define two functions h, k : Y → {0, 1}: let h(y) = 1 when y is a value of e and h(y) = 0 otherwise, and let k(y) = 1 always. Then h ∘ e = k ∘ e, both being constantly 1. Cancelling e gives h = k, which says every y is a value of e. ∎

Look at the two harder halves. To test a function we probed it with a well-chosen set — a one-element set to detect injectivity, a two-element set to detect surjectivity. Studying an object through the arrows from or to a few special objects is a technique this course keeps returning to.

One-sided inverses

Between “cancellable” and “invertible” sits a useful middle notion.

Definition · Section & retraction

If r ∘ s = idX, for arrows s : X → Y and r : Y → X, then s is called a section of r, and r a retraction of s. An arrow that has a retraction is a split monomorphism; an arrow that has a section is a split epimorphism.

Proposition · Split implies cancellable

Every section is monic, and every retraction is epic.

Proof. Let r ∘ s = id. If s ∘ h = s ∘ k, compose with r on the left: h = r ∘ s ∘ h = r ∘ s ∘ k = k. If h ∘ r = k ∘ r, compose with s on the right: h = h ∘ r ∘ s = k ∘ r ∘ s = k. ∎

So the special arrows form two ladders:

isomorphism  ⟹  split mono  ⟹  mono,

isomorphism  ⟹  split epi  ⟹  epi.

None of the implications reverses in general. In Set an injective function with non-empty domain always has a retraction (send the points outside its image anywhere you like), but the empty function ∅ → Y into a non-empty set is monic and has none. And the statement “every surjective function has a section” is precisely the axiom of choice.

Mono and epi together are not iso

In Set, injective plus surjective equals bijective. It is tempting to guess that “monic and epic” always means “isomorphism.” It does not, and the failure happens in the humblest categories we have. In the chain 𝟚, the arrow 0 → 1 is monic and epic — in a thin category every arrow is, since any two parallel arrows are already equal — yet it is not an isomorphism, because there is no arrow 1 → 0 at all (Exercise 15).

The same thing happens among honest structure-preserving functions. In Mon, consider the inclusion i : (ℕ, +) → (ℤ, +). It is injective, hence monic. It is certainly not surjective. But it is epic. Suppose h, k : ℤ → M are monoid homomorphisms that agree on ℕ, and take n ≥ 0. Then h(−n) is a two-sided inverse of h(n) in M, because h(−n) · h(n) = h(0) = e = h(n) · h(−n); likewise k(−n) is a two-sided inverse of k(n), which equals h(n). Inverses in a monoid are unique — the argument of Exercise 10(b) — so h(−n) = k(−n). Hence h = k. A homomorphism out of ℤ is determined by what it does on ℕ, even though ℕ is not all of ℤ.

So i is monic and epic but not an isomorphism, and “epic” does not mean “onto” outside Set. Cancellation and invertibility are different ideas that happen to coincide for sets. What is true in every category is a slightly weaker statement, which Exercise 16 asks you to prove: an arrow that is monic and has a section is an isomorphism.

§2 · Exercises 1–5

Exercise 1warm-up

Let A = {1, 2}, B = {a, b} and C = {10, 20}. Let f : A → B be the function with f(1) = a and f(2) = b, and let g : B → C be the function with g(a) = 10 and g(b) = 20.

Write down the composite g ∘ f : A → C by saying where it sends each element of A. Then say, in one sentence, why the notation g ∘ f — with g written first — nevertheless means “apply f first.”

Show solution

Tracing each element: 1 ↦ a ↦ 10 and 2 ↦ b ↦ 20, so g ∘ f sends 1 to 10 and 2 to 20. (For readers following the Python track: with the two functions stored as dictionaries f and g, the composite is {x: g[f[x]] for x in f}.)

The order comes from function application: (g ∘ f)(x) is defined to be g(f(x)), and reading g(f(x)) inside-out, the innermost function — f — acts first. The arrow written last is applied first. This right-to-left convention trips up almost everyone at least once, which is why it is Exercise 1.

Exercise 2arrows-only

The definition of a category asks for an identity arrow on each object. This exercise shows the wording could have said the identity arrow.

Suppose i : X → X and i′ : X → X both behave as identities on X — that is, each satisfies the identity law: composing with either of them, on either side, changes nothing. Prove that i = i′, using nothing but the identity law itself.

Show solution

Consider the single composite i′ ∘ i and evaluate it twice. Because i′ acts as an identity (applied on the left), i′ ∘ i = i. Because i acts as an identity (applied on the right), i′ ∘ i = i′. One arrow, two names: i = i′.

Notice what the proof did not use: anything about what X is, or contains. It is pure arrow-pushing, and it licenses the notation idX — the identity on X — for the rest of the course.

Exercise 3examples

Each of the following proposes a category whose objects are all sets. For each, decide whether it really is a category, and if not, identify exactly which requirement fails.

  1. Arrows are the injective functions.
  2. Arrows are the surjective functions.
  3. Arrows are the functions that are not the identity.
  4. Arrows are the functions that have at least one fixed point (some x with f(x) = x).
Show solution

(a) Yes and (b) yes. A composite of injections is an injection, a composite of surjections is a surjection, and the identity function is both — each class is closed under composition and contains all the identities it needs. Associativity is inherited from ordinary function composition.

(c) No, twice over: it excludes the identity arrows by fiat, and it is not even closed under composition — a bijection composed with its inverse lands exactly on an identity, which the class forbids.

(d) No, and this one is sneakier. Almost all the identities are present — every point of idX is fixed — but not quite all: the identity on the empty set has no points, hence no fixed point, so ∅ is left without an identity. And even among non-empty sets, closure fails. On {a, b, c}, let f swap a, b and fix c, and let g swap b, c and fix a. Each has a fixed point, but tracing the composite g ∘ f element by element gives the 3-cycle a ↦ c, b ↦ a, c ↦ b, which fixes nothing. The moral of (c) and (d): the closure conditions are not bureaucratic fine print; drop them and the structure genuinely collapses.

Exercise 4structure

Every category has an evil twin. Given a category 𝒞, define its opposite category 𝒞op as follows: the objects are the same, but each arrow f : X → Y of 𝒞 is reinterpreted as an arrow f : Y → X of 𝒞op, and composition is defined by g ∘op f = f ∘ g, using the composition of 𝒞 on the right.

Verify that 𝒞op satisfies the two category laws, taking care with the order of composition. What is (𝒞op)op?

Show solution

Typing. If in 𝒞op we can form g ∘op f, then (unwinding the reversed directions) f ∘ g is composable in 𝒞, and its reinterpretation has exactly the right source and target — so the definition makes sense.

Identities. The same arrows idX serve: id ∘op f = f ∘ id = f and f ∘op id = id ∘ f = f, both by the identity law of 𝒞.

Associativity. h ∘op (g ∘op f) = (f ∘ g) ∘ h and (h ∘op g) ∘op f = f ∘ (g ∘ h); these agree by associativity in 𝒞.

Finally, reversing all arrows twice restores every arrow to its original direction, and the composition unwinds too: (𝒞op)op = 𝒞. Remember this construction — in Lessons 5 and 6 it becomes the duality principle, which lets every theorem be proved twice for the price of once.

Exercise 5structure

Given categories 𝒞 and 𝒟, define the product category 𝒞 × 𝒟: objects are pairs (C, D), arrows are pairs (f, g) of arrows, composed slotwise: (f′, g′) ∘ (f, g) = (f′ ∘ f, g′ ∘ g).

Say what the identity on (C, D) must be, and verify both category laws. (File this construction away — Lesson 5 studies it alongside other ways of building new categories from old, and it is the stage on which Lesson 8 exhibits products and coproducts as adjoints.)

Show solution

The identity is (idC, idD), since composing slotwise with it applies each ordinary identity law in its own slot: (f, g) ∘ (id, id) = (f ∘ id, g ∘ id) = (f, g), and likewise on the left.

Associativity is the same story: ((f″, g″) ∘ (f′, g′)) ∘ (f, g) and (f″, g″) ∘ ((f′, g′) ∘ (f, g)) both compute, slot by slot, to (f″ ∘ f′ ∘ f,  g″ ∘ g′ ∘ g) — each slot protected by the associativity of its own category. Nothing interacts across slots, which is the whole design. Constructions like this, where the laws hold “componentwise for free,” recur constantly: the functor category of Lesson 3 will inherit its laws pointwise in exactly the same way.

Diagrams and examples

§3–§4 · Exercises 6–8

Exercise 6counting

Build the category 𝟛 from the chain 0 ≤ 1 ≤ 2, the same way 𝟚 was built from 0 ≤ 1.

How many arrows does 𝟛 have in total? List them. Then generalize: how many arrows does the chain 0 ≤ 1 ≤ ⋯ ≤ n have as a category?

Show solution

𝟛 has 6 arrows: the three identities on 0, 1, 2, the two generating arrows 0 → 1 and 1 → 2, and the composite 0 → 2. The last one is the arrow people forget — but transitivity of ≤ means it is there, and closure under composition obliges you to include it.

In general there is exactly one arrow i → j for each ordered pair with i ≤ j. Counting pairs: (n+1)(n+2)/2 arrows — the triangular numbers. For n = 2 this gives 6, as counted by hand.

Exercise 7arrows-only

In §4, example (ii), we turned any preorder into a category by drawing exactly one arrow x → y whenever x ≤ y.

Explain why, in such a category, every diagram commutes — no matter how many objects and arrows it has, and without checking a single composite.

Show solution

A diagram commutes when any two directed paths with the same start and end compose to the same arrow. In a preorder-as-category there is at most one arrow between any ordered pair of objects. Two paths from x to y compose to two arrows x → y — and since at most one such arrow exists, they are forced to be equal. Commutativity is automatic.

Categories with this at-most-one-arrow property are called thin. They carry order information but no information about how one object maps to another — which is exactly why they make such clean test cases for definitions later in the course.

Exercise 8structure

§4 claimed that a monoid is the same thing as a one-object category. A group is a monoid in which every element has an inverse.

State the full dictionary that translates “one-object category in which every arrow is invertible” into “group,” and back: say what the arrows, the composition, the identity arrow, and the invertibility condition each become on the group side, and check that the axioms match up.

Show solution

The single object carries no information — it is just a peg to hang arrows on. The arrows become the group’s elements; composition of arrows becomes the group operation; the identity arrow becomes the identity element e; and “every arrow is invertible” — for each f there is a g with g ∘ f = f ∘ g = id — becomes the existence of inverses.

The category axioms translate line for line: associativity of composition is associativity of the operation, and the identity law is the unit law. So: groups are exactly the one-object categories in which every arrow is invertible. Drop the invertibility requirement and the same dictionary yields monoids, as in example (iii) of §4.

Isomorphisms

§5 · Exercises 9–11

Exercise 9warm-up

Isomorphic or not? Decide each case, and where the answer is yes, exhibit an isomorphism.

  1. In Set: the sets {1, 2, 3} and {x, y, z}. How many different isomorphisms are there between them?
  2. In the integers ordered by divisibility (a preorder, as in §5): 4 and 6; then 5 and −5.
  3. In Mat: the objects 2 and 3.
  4. In the one-object category of the monoid (ℤ/4, ·) — the numbers 0, 1, 2, 3 under multiplication modulo 4 — which arrows are isomorphisms?
Show solution

(a) Yes. Any bijection is an isomorphism, for instance 1 ↦ x, 2 ↦ y, 3 ↦ z. There are 3! = 6 of them: three choices for the image of 1, two remaining for 2, one for 3.

(b) 4 and 6: no — isomorphic would mean each divides the other, and neither does. 5 and −5: yes — 5 divides −5 and −5 divides 5. The two arrows compose to identities automatically, because a preorder has at most one arrow 5 → 5.

(c) No. An isomorphism 2 → 3 would be an invertible 3 × 2 matrix, and invertible matrices are square.

(d) The isomorphisms are the elements with a multiplicative inverse modulo 4: 1 (its own inverse) and 3 (since 3 · 3 = 9 ≡ 1). The elements 0 and 2 are not invertible: every multiple of 0 is 0, and every multiple of 2 is even, so neither can reach 1.

Exercise 10arrows-only

An arrow f : X → Y is an isomorphism if there exists g : Y → X with g ∘ f = idX and f ∘ g = idY. Prove three basic facts, each by pure arrow-pushing:

  1. Every identity arrow is an isomorphism.
  2. The inverse of an isomorphism is unique (so we may write f−1).
  3. A composite of isomorphisms is an isomorphism, and (g ∘ f)−1 = f−1 ∘ g−1 — note the reversal of order.
Show solution

(a) idX is its own inverse: id ∘ id = id, twice over.

(b) Suppose g and g′ are both two-sided inverses of f. Then g = g ∘ id = g ∘ (f ∘ g′) = (g ∘ f) ∘ g′ = id ∘ g′ = g′. The middle step is associativity; everything else is the inverse and identity laws. This mirrors Exercise 2 — uniqueness proofs in category theory tend to have exactly this shape.

(c) Check that f−1 ∘ g−1 inverts g ∘ f: (f−1 ∘ g−1) ∘ (g ∘ f) = f−1 ∘ (g−1 ∘ g) ∘ f = f−1 ∘ id ∘ f = f−1 ∘ f = id, and symmetrically on the other side. The reversal of order is forced by the typing: to undo “first f, then g,” you must undo g first — socks and shoes.

Exercise 11arrows-only

Let f : X → Y be an isomorphism in any category. Show that the automorphism groups of X and Y are isomorphic as groups, by checking that

φ  ↦  f ∘ φ ∘ f−1

sends automorphisms of X to automorphisms of Y, respects composition and identities, and has an inverse of the same form.

Show solution

Write c(φ) = f ∘ φ ∘ f−1. If φ : X → X is an isomorphism then c(φ) : Y → Y is a composite of three isomorphisms, hence an isomorphism (Exercise 10(c)): an automorphism of Y.

Composition. c(φ) ∘ c(ψ) = f ∘ φ ∘ f−1 ∘ f ∘ ψ ∘ f−1 = f ∘ φ ∘ ψ ∘ f−1 = c(φ ∘ ψ), the middle pair f−1 ∘ f cancelling. Identity. c(idX) = f ∘ f−1 = idY.

Inverse. The map d(θ) = f−1 ∘ θ ∘ f goes back from Aut(Y) to Aut(X), and d(c(φ)) = f−1 ∘ f ∘ φ ∘ f−1 ∘ f = φ; likewise c(d(θ)) = θ. So c is a bijective homomorphism of groups whose inverse d is also a homomorphism: Aut(X) ≅ Aut(Y). This is the slogan of §5 at work — isomorphic objects cannot be told apart, not even by their symmetries.

Finite categories by hand

§6 · Exercises 12–14

Exercise 12by hand · optional python

The commuting square is the category with four objects A, B, C, D, their four identities, and five more arrows: f : A → B, p : A → C, q : B → D, g : C → D, and a diagonal d : A → D with q ∘ f = d = g ∘ p — the square of §3, with its diagonal given a name.

Write out its composition table in the style of §6. How many composable pairs are there? Then explain why associativity needs no checking.

Optional · Python

Encode the category 𝟛 of §6 as a FiniteCategory — objects, all six arrows, the composition table, and the identities — and run .check() to confirm it satisfies all four requirements.

Hint: because 𝟛 is thin, there is at most one arrow between any two objects, so every entry of the composition table is forced; you can generate the table with a small helper rather than writing it out by hand.

Show solution

By hand. There are nine arrows. Each arrow x composes with an identity at either end, giving id ∘ x and x ∘ id: that is 9 + 9 = 18 pairs, of which the four pairs “identity with itself” were counted twice, leaving 14. The only composable pairs of non-identity arrows are (q, f) and (g, p), each with composite d. So the table has 16 entries out of 81, and only two of them — q ∘ f = d and g ∘ p = d — are not dictated by the identity law.

Associativity: a composable triple of non-identity arrows would be a path of three steps, and the longest paths here (A → B → D and A → C → D) have two. Triples containing an identity are covered by the identity law. (Alternatively: the category is thin, so nothing needs checking.)

Optional · Python

For 𝟛: name the three identities and the three non-trivial arrows, then let a helper fill the forced composition table:

three.py
objs = {0, 1, 2}
ar = {'i0':(0,0), 'i1':(1,1), 'i2':(2,2),
      'a':(0,1), 'b':(1,2), 'c':(0,2)}        # c is forced:  b . a
ident = {0:'i0', 1:'i1', 2:'i2'}

# at most one arrow per ordered pair, so each composite is determined
def only(s, t):
    return next(n for n,(d,c) in ar.items() if d==s and c==t)
comp = {(g,f): only(ar[f][0], ar[g][1])
        for g in ar for f in ar if ar[f][1]==ar[g][0]}

print(FiniteCategory(objs, ar, comp, ident).check())   # True
outputTrue

The comment on the arrow c is the real content: once you accept a : 0 → 1 and b : 1 → 2, the category has no choice but to contain their composite.

Exercise 13by hand · optional python

A checker — human or machine — is only trustworthy once you have seen it catch a mistake. Corrupt two of §6’s tables on purpose.

  1. In the table of 𝟛, change one entry: declare b ∘ a = i0, claiming that 0 → 1 followed by 1 → 2 is the identity on 0. Which requirement of the definition does the new table violate, and why?
  2. In the table of (ℤ/3, +), change the single entry 1 ∘ 1 from 2 to 0. Typing is untouched and the identity law still holds. Find a triple at which associativity fails.
Optional · Python

Make corruption (a) in your encoding of 𝟛 from Exercise 12: set comp[('b','a')] = 'i0'. Predict which of the four checks in check() fires, then run it.

Show solution

(a) Typing. The composite of a : 0 → 1 and b : 1 → 2 must be an arrow 0 → 2, but i0 runs 0 → 0. The table is rejected before the identity law or associativity is even consulted.

This is worth internalizing: most bookkeeping errors in category theory are typing errors, and they are caught mechanically, before any interesting law is consulted. It is the same discipline a type-checker imposes on a program — which is not a coincidence.

(b) Associativity. The row and column of the identity 0 are unchanged, so the identity law survives. But (1 ∘ 1) ∘ 2 = 0 ∘ 2 = 2, while 1 ∘ (1 ∘ 2) = 1 ∘ 0 = 1. One altered entry, and the table no longer describes a category.

Optional · Python

Exercise 14counting

Classify small categories by hand. Two categories count as “the same” here if one becomes the other by renaming objects and arrows.

  1. How many categories have exactly one object and two arrows?
  2. How many categories have exactly two objects and three arrows?

Hint: decide where the non-identity arrows can go, then ask which composition tables the laws allow.

Show solution

(a) Two. One arrow must be the identity e; call the other a. The only free entry in the composition table is a ∘ a, which is either e or a. Both choices are associative (with a single non-identity arrow, every bracketing of a ∘ a ∘ a gives the same result — check both cases), so both are categories: the group ℤ/2, where a ∘ a = e, and the monoid with an idempotent, where a ∘ a = a (for instance {1, 0} under multiplication). They are genuinely different: in the first a is an isomorphism, in the second it is not.

(b) Three. Two of the three arrows are the identities, leaving one more arrow u. Either u runs between the two objects — say u : X → Y, the other direction being the same up to renaming — and then no composite is free: this is 𝟚. Or u is a loop at one object, and as in part (a) either u ∘ u = id or u ∘ u = u. So there are three: 𝟚, and the two monoids of part (a) each sitting beside a lone extra object.

Monomorphisms and epimorphisms

Going deeper · Exercises 15–16

Exercise 15arrows-only

Using only the cancellation definitions from the Going-deeper section:

  1. Show every isomorphism is both monic and epic.
  2. Show that in a preorder-as-category every arrow is both monic and epic — and conclude, using an arrow of the chain 𝟚, that “mono and epi” does not imply “iso.”
Show solution

(a) Suppose m has inverse m−1 and m ∘ h = m ∘ k. Compose both sides on the left with m−1 and use associativity: h = (m−1 ∘ m) ∘ h = (m−1 ∘ m) ∘ k = k. Right-cancellation is the mirror computation with m−1 on the other side.

(b) In a thin category, any two parallel arrows h, k with the same source and target are already equal — so the implication “m ∘ h = m ∘ k ⟹ h = k” holds trivially for every m, its conclusion being always true, and likewise its dual. Now take the unique arrow u : 0 → 1 in 𝟚: it is monic and epic by the above, but it is not an isomorphism, since there is no arrow 1 → 0 at all. The moral: bijectivity is a theorem about Set, not a consequence of the axioms — cancellation and invertibility are genuinely different ideas that happen to coincide there.

Exercise 16arrows-only

Cancellation, practised. In any category, prove:

  1. A composite of two monomorphisms is a monomorphism.
  2. If g ∘ f is monic, then f is monic.
  3. If g ∘ f is epic, then g is epic.
  4. If f is monic and has a section — an arrow s with f ∘ s = id — then f is an isomorphism.
Show solution

(a) Let f : X → Y and g : Y → Z be monic and suppose (g ∘ f) ∘ h = (g ∘ f) ∘ k. Re-bracket: g ∘ (f ∘ h) = g ∘ (f ∘ k). Cancel g, then cancel f: h = k.

(b) Suppose f ∘ h = f ∘ k. Compose with g on the left: (g ∘ f) ∘ h = (g ∘ f) ∘ k. Since g ∘ f is monic, h = k.

(c) The mirror image of (b): if h ∘ g = k ∘ g, compose with f on the right to get h ∘ (g ∘ f) = k ∘ (g ∘ f) and cancel the epimorphism g ∘ f.

(d) We know f ∘ s = idY and must show s ∘ f = idX. Compute f ∘ (s ∘ f) = (f ∘ s) ∘ f = idY ∘ f = f = f ∘ idX. Now cancel the monomorphism f on the left: s ∘ f = idX. So s is a two-sided inverse.

Part (d) is the precise sense in which “mono and epi” falls short of “iso”: an epimorphism is merely right-cancellable, while a section is an actual right inverse, and it takes the stronger property to finish the proof.

The category of relations

§4–§5 · Exercises 17–19

Exercise 17examples

Work in Rel (§4, example vi). Let R be the relation from {1, 2} to {a, b, c} consisting of the pairs (1, a), (1, b), (2, c), and let S be the relation from {a, b, c} to {x, y} consisting of (a, x), (b, y), (c, y).

  1. Compute the composite S ∘ R.
  2. Every relation R from X to Y has a converse R° from Y to X, obtained by reversing every pair. Show that (S ∘ R)° = R° ∘ S° for all composable relations.
  3. Which arrows of Rel are graphs of functions? State the two conditions on R.
Show solution

(a) Chain each pair of R through a matching pair of S: 1 R a and a S x give (1, x); 1 R b and b S y give (1, y); 2 R c and c S y give (2, y). So S ∘ R = { (1, x), (1, y), (2, y) } — note that 1 is related to two different elements.

(b) The pair (z, x) lies in (S ∘ R)° exactly when (x, z) ∈ S ∘ R, that is, when there is a y with x R y and y S z. Reversing both pairs, that says: there is a y with z S° y and y R° x — which is the definition of (z, x) ∈ R° ∘ S°. The order of composition flips, exactly as for inverses in Exercise 10(c).

(c) R is the graph of a function X → Y when every x is related to at least one y (the function is defined everywhere) and to at most one y (it is single-valued). The relation S ∘ R of part (a) fails the second condition at x = 1.

Exercise 18think

Which arrows of Rel are isomorphisms? Show that a relation R from X to Y has a two-sided inverse in Rel exactly when it is the graph of a bijection.

Hint: let S be the inverse, so that S ∘ R and R ∘ S are the equality relations. Use the first to find, for each x, some y with x R y and y S x; use the second to show that y is the only element related to x.

Show solution

If R is the graph of a bijection f, its converse R° is the graph of f−1, and the two composites are the equality relations. So graphs of bijections are isomorphisms.

Conversely, suppose S ∘ R is equality on X and R ∘ S is equality on Y. Fix x. Since (x, x) ∈ S ∘ R, there is a y with x R y and y S x: so x is related to at least one element. Suppose also x R y′. Then y S x and x R y′ give (y, y′) ∈ R ∘ S, and R ∘ S is equality, so y = y′: x is related to at most one element. By Exercise 17(c), R is the graph of a function f. The same argument with the roles of R and S exchanged shows S is the graph of a function g, and the two equations say g ∘ f = idX and f ∘ g = idY. So f is a bijection.

The isomorphisms of Rel are therefore the same as the isomorphisms of Set, even though Rel has vastly more arrows. Adding arrows to a category can create new isomorphisms; here it happens not to.

Exercise 19structure

The converse operation of Exercise 17 can be read as a comparison between Rel and its opposite category (Exercise 4).

Describe a way of turning each arrow R : X → Y of Rel into an arrow X → Y of Relop that respects identities and composition and can be undone. What does this say about the relationship between a relation and its converse?

Show solution

An arrow X → Y of Relop is, by definition, an arrow Y → X of Rel — a relation from Y to X. Send R to its converse R°, which is exactly such a relation. Identities are respected, since the converse of an equality relation is itself. Composition is respected: the composite of R° and S° in the opposite category is, by definition, the composite in the other order in Rel, namely R° ∘ S°, and Exercise 17(b) says this is (S ∘ R)°. And the assignment undoes itself, because R°° = R.

So Rel is the same as its own opposite: every statement about relations has a mirror image obtained by reversing them. In Lesson 2 an assignment like this — objects to objects, arrows to arrows, identities and composites preserved — gets a name, functor, and Lesson 5 returns to categories that are their own duals.

Recap

What to carry forward

  1. A category is objects + typed arrows + composition + identities, obeying associativity and the identity law. Nothing more.
  2. The arrows are the content. Whenever you’re tempted to reach inside an object, ask whether you can say the same thing with arrows instead — you usually can.
  3. Commutative diagrams are equations. A diagram commutes when same-endpoint paths compose equally.
  4. The definition is a wide net: Set, every preorder, every monoid, every group, and the world of typed programs are all categories.
  5. An isomorphism is an arrow with a two-sided inverse: the arrows-only notion of sameness. Isomorphic objects have the same arrows to and from everything else; monic and epic arrows are the cancellable ones, and being both does not make an arrow an isomorphism.
  6. For a finite category the laws are checkable — by hand from its composition table, or by the optional checker.
