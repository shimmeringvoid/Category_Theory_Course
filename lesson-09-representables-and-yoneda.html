§1 — One pattern, three lessons

A slogan to prove and a coincidence to explain

Since Lesson 1 this course has repeated one article of faith: never look inside an object; its arrows tell you everything. We have practiced the discipline — arrows-only proofs, universal properties, adjunctions — but the article of faith itself was never proved. The Yoneda lemma proves it. It says, precisely, that the totality of arrows into an object, organized functorially, determines that object up to isomorphism — and even determines the maps between objects. The slogan graduates from methodology to theorem.

There is a second reason to study the totality of arrows into an object. Look back at the three lessons just finished, and at the sentence each of them turned on:

  • Lesson 6: an arrow into a product A × B is the same thing as a pair of arrows, one into A and one into B.
  • Lesson 7: an arrow into a limit of D is the same thing as a cone over D.
  • Lesson 8: an arrow out of F X into Y is the same thing as an arrow from X into U Y.

Each sentence describes all the arrows into, or out of, some object, without saying anything about what the object is made of. And in each lesson that description was the definition: it determined the object up to a unique isomorphism, by an argument that had to be repeated three times.

That is not a coincidence, and this lesson explains it. The sets of arrows into an object A form a functor. The three sentences each say that this functor is naturally isomorphic to another functor — pairs of arrows, cones, arrows into U Y — which can be written down before the object is known. Such an object is said to represent the functor. So there are two things to do. One is to prove the Yoneda lemma. The other is to see that a universal property is a representation of a functor, so that the uniqueness arguments of Lessons 6, 7 and 8 become a single corollary.

§2 — Functors into Set

Sets that vary with an object

Lesson 2 introduced the hom functors. For a fixed object A of a category 𝒞 — locally small, as always when hom-sets are mentioned — there are two of them:

  • the covariant 𝒞(A, −) : 𝒞 → Set, which sends X to the set of arrows A → X, and an arrow k : X → Y to the function “compose with k afterwards”;
  • the contravariant 𝒞(−, A) : 𝒞op → Set, which sends X to the set of arrows X → A, and an arrow g : X → Y to the function “compose with g beforehand,” from 𝒞(Y, A) to 𝒞(X, A).

The second is the one in the picture at the top of the page. The arrows into A do not form a single set — they form one set per source object, and those sets are related: any arrow g : X → Y converts Y-probes of A into X-probes, by precomposition h ↦ h ∘ g. Sets indexed by objects, translated along arrows — contravariantly, since g points one way and the conversion points the other. That is a functor on the opposite category of Lesson 5:

Definition · Presheaf · representable presheaf

A presheaf on 𝒞 is a functor 𝒞op → Set. Each object A gives the presheaf yA = 𝒞(−, A): on objects, yA(X) = 𝒞(X, A), the set of arrows X → A; on arrows, precomposition. Functoriality is Lesson 1’s two laws, read backwards: h ∘ id = h and (h ∘ g) ∘ g′ = h ∘ (g ∘ g′).

In the language of Lesson 6, yA(X) is the set of generalized elements of A of shape X. The presheaf yA is the hero picture made precise: the complete dossier of arrows into A, with its bookkeeping.

Functors into Set are data

A presheaf need not come from an object. In general it is best regarded as a structure made of sets: one set for each object of 𝒞, one function for each arrow, and the equations of 𝒞 respected. Earlier lessons had examples in covariant form: a functor from a one-object category to Set is a set with an action of a monoid (Lesson 2), and a functor from a discrete category is a family of sets (Lesson 5). Here is one more, which will serve as the running example of this lesson.

Let 𝒢 be the category with two objects V and E and, besides the identities, exactly two arrows s, t : V → E. A presheaf G on 𝒢 consists of two sets, G(V) and G(E), and — because a presheaf reverses arrows — two functions G(s), G(t) : G(E) → G(V). Call the elements of G(V) vertices and those of G(E) edges, and read G(s) and G(t) as the source and the target of an edge:

a presheaf on 𝒢  =  a directed graph.

Loops and parallel edges are allowed, since nothing forbids them. A natural transformation between two such presheaves is a function on vertices together with a function on edges, and the two naturality squares say that it sends the source of an edge to the source of its image and the target to the target. That is a graph homomorphism. So the category of presheaves on 𝒢 is the category of directed graphs.

This is the sense in which Lesson 2 called functors into Set “data structures.” A small category is a schema; a presheaf on it is an instance of the schema; a natural transformation is a structure-preserving map between instances.

Representable functors

Among all the functors into Set, the hom functors are special, and so is anything that is one of them in disguise.

Definition · Representable functor

A functor F : 𝒞 → Set is representable if it is naturally isomorphic to 𝒞(A, −) for some object A. A presheaf F : 𝒞op → Set is representable if it is naturally isomorphic to yA = 𝒞(−, A) for some A. The object A is said to represent F, and a representation of F is a choice of A together with a natural isomorphism.

To say that F is representable is to say that the sets F(X) are, uniformly in X, sets of arrows. A gallery — most of it collected from earlier lessons, where the word was not yet available:

Not every functor into Set is representable, and there is a quick test. By Lesson 7 a hom functor 𝒞(A, −) preserves every limit — in particular it sends a terminal object to a one-element set, because there is exactly one arrow from A to a terminal object. So:

  • the covariant power set functor P : Set → Set is not representable: P of a one-element set has two elements;
  • the list functor List : Set → Set is not representable: there are infinitely many lists over a one-element set;
  • the functor X ↦ X + 1 is not representable, for the same reason.

Exercise 1 has more cases of both kinds.

§3 — The Yoneda lemma

Track the identity

The Yoneda lemma says that the dossier yA omits nothing. Its general form compares yA with an arbitrary presheaf.

Let F be any presheaf on 𝒞 and A an object. What are the natural transformations from yA to F? There is one obvious thing to do with such a transformation α. Its component at A is a function αA from 𝒞(A, A) to F(A), and the set 𝒞(A, A) contains one arrow that is certain to exist: the identity. So every α produces an element αA(idA) of F(A). The lemma says that this element is all there is to α.

Theorem · The Yoneda lemma

For every presheaf F and every object A, natural transformations yA ⇒ F correspond exactly to elements of F(A):

Nat(yA, F)  ≅  F(A),

via α ↦ αA(idA). A natural transformation out of a representable is determined by where it sends the identity.

Proof. Given α : yA ⇒ F, set a = αA(idA) ∈ F(A). For any f : X → A, the naturality square at f (drawn above) forces αX(f) = F(f)(a) — because f = idA ∘ f, the left edge sends idA to f, and the two paths around the square must agree. So α is completely determined by a: the correspondence is injective. Conversely, any a ∈ F(A) defines a transformation by that same formula αX(f) = F(f)(a), and its naturality squares commute by the functoriality of F (Exercise 2 checks this half in detail). Surjective and injective: a bijection. ∎

“Track the identity” is the entire idea — the identity arrow is the generic probe, and every other probe is the generic one, translated. The proof is short enough to memorise, and it produces a formula worth memorising with it:

the transformation belonging to a ∈ F(A) is   αX(f) = F(f)(a).

Two remarks before the examples. First, the lemma has a covariant twin, for functors F : 𝒞 → Set and the hom functor 𝒞(A, −) of arrows out of A: Nat(𝒞(A, −), F) ≅ F(A), by the same proof (Exercise 4). Second, the bijection is not an accident of sizes: it is itself natural, both in A and in F (Exercise 3 checks the first).

Reading the lemma in an order

Let P be a poset, and consider presheaves on it whose values are either empty or a one-element set. Such a presheaf F is the same thing as a down-closed subset S of P — the set of x where F(x) is inhabited; contravariance says that if y is in S and x ≤ y, then x is in S. The representable ya is the down-set ↓a of all x ≤ a. Between two presheaves of this kind there is at most one natural transformation, and there is one exactly when the first subset is contained in the second. So the Yoneda lemma reads:

↓a ⊆ S   if and only if   a ∈ S.

A down-closed set contains everything below a as soon as it contains a itself. Nobody needs a lemma for this — but notice where the proof lives: a belongs to ↓a because a ≤ a. The identity is being tracked.

Reading the lemma for a monoid

Let M be a monoid, regarded as a category with one object ∗. A presheaf on it is a set S on which M acts on the right: each m gives a function s ↦ s · m, with s · e = s and (s · m) · n = s · (m n). A natural transformation is a function that commutes with the action, an equivariant map. The one representable presheaf, y∗, is the set M itself, acting on itself by multiplication on the right.

So the Yoneda lemma is a statement about equivariant maps α : M → S. Such a map satisfies α(m) = α(e · m) = α(e) · m, so it is determined by the single element α(e) — the image of the identity — and any element s of S may be chosen for it, giving the map m ↦ s · m. Equivariant maps M → S correspond to elements of S.

Take S = M. The equivariant maps from M to itself are exactly the maps m ↦ a m: multiplication on the left by a fixed element, one for each a in M. §6 counts them for ℤ/3, where 3 of the 27 functions survive.

Reading the lemma for graphs

On the category 𝒢 of §2 there are two representable presheaves, and they can be computed from the definition yA(X) = 𝒢(X, A).

  • yV has vertex set 𝒢(V, V) = {idV} and edge set 𝒢(E, V) = ∅. It is the graph with one vertex and no edges.
  • yE has vertex set 𝒢(V, E) = {s, t} and edge set 𝒢(E, E) = {idE}. The source of its one edge is idE ∘ s = s and its target is t. It is the graph with two vertices and one edge between them.

Now let G be any graph. The Yoneda lemma says

homomorphisms yV → G  ≅  vertices of G,

homomorphisms yE → G  ≅  edges of G.

Both are plain to see. A homomorphism from a one-vertex graph chooses a vertex. A homomorphism from the one-edge graph chooses an edge of G for its edge — and then has no choice about the two vertices, which must go to the source and target of the chosen edge. The element being tracked is idE, the edge of yE.

The example shows what a representable presheaf is, in general: yA is the structure freely generated by one element of sort A, namely idA. It contains that element, whatever the arrows of the category force to exist along with it, and nothing else. Mapping out of it means choosing where the generator goes.

Reading the lemma in Set

The covariant form of the lemma, applied to functors Set → Set, classifies natural transformations that would be tedious to find by inspection. The identity functor is represented by a one-element set, so for any F : Set → Set,

Nat(Id, F) ≅ Nat(Set(1, −), F) ≅ F(1).

  • F = Id: one natural transformation, the identity. Lesson 3’s Exercise 9 proved this by tracking an element 1 → X, which is the Yoneda argument.
  • F = P, the covariant power set: P(1) has two elements, so there are exactly two natural transformations Id ⇒ P. They are x ↦ ∅ and the singleton map x ↦ {x} of Lesson 3.
  • F = List: the lists over a one-element set are determined by their length, so natural transformations Id ⇒ List correspond to natural numbers. The n-th one sends x to the list [x, x, …, x] of length n.

Likewise the squaring functor is represented by 2, so natural transformations from X × X to F X correspond to elements of F(2). With F = Id there are two, and they are the two projections: the only natural ways to choose one of two elements are “the first” and “the second.” Exercise 5 does several more of these counts.

§4 — The Yoneda embedding

An object is the arrows into it

Two consequences fall out immediately. The first comes from taking F to be another representable.

The assignment A ↦ yA is a functor y from 𝒞 to the category [𝒞op, Set] of presheaves — the functor categories of Lesson 3, now indispensable. On an arrow h : A → B it gives the natural transformation y(h) : yA ⇒ yB whose components are “compose with h afterwards”: an arrow f : X → A goes to h ∘ f : X → B. Naturality is the associative law.

Theorem · The Yoneda embedding

The functor y : 𝒞 → [𝒞op, Set] is full and faithful: every natural transformation yA ⇒ yB is composition with exactly one arrow A → B.

Proof. Apply the lemma with F = yB: natural transformations yA ⇒ yB correspond to elements of yB(A) = 𝒞(A, B). By the formula of §3, the transformation belonging to h ∈ 𝒞(A, B) has components αX(f) = yB(f)(h) = h ∘ f — and that is y(h). So h ↦ y(h) is a bijection from 𝒞(A, B) to Nat(yA, yB). ∎

So 𝒞 sits inside its category of presheaves as a full subcategory, the representables. Lesson 2 said that in a thin category the hom functors are the order, repackaged; in every category they repackage the whole category, arrows included. For graphs: the two-object category 𝒢 reappears as the full subcategory of graphs consisting of the lone vertex and the lone edge — there are exactly two homomorphisms from the vertex to the edge, s and t, and none the other way.

The second consequence is the one the course has been promising. Fully faithful functors reflect isomorphisms (Lesson 2), so:

Aside · The slogan, q.e.d.

A ≅ B  if and only if  yA ≅ yB. Two objects with the same arrows into them — the same dossier, naturally in the probing object — are isomorphic. An object is the arrows into it. In a poset this says something you can compute: an element is determined by its down-set, and §6 checks it, element by element, in the divisibility order.

Dually, by the covariant form of the lemma, A ≅ B if and only if 𝒞(A, −) ≅ 𝒞(B, −): an object is also the arrows out of it.

Proving isomorphisms without constructing them

The corollary gives a method. To show that two objects are isomorphic, compute the arrows into each from an arbitrary X, and show that the answers agree naturally in X. Often the computation is nothing but a chain of universal properties.

Products are associative. For any X,

𝒞(X, (A × B) × C)  ≅  (𝒞(X, A) × 𝒞(X, B)) × 𝒞(X, C)

≅  𝒞(X, A) × (𝒞(X, B) × 𝒞(X, C))  ≅  𝒞(X, A × (B × C)).

The outer steps use the universal property of the product twice each; the middle step is the associativity of the product of sets. Every step is natural in X, so (A × B) × C ≅ A × (B × C). Lesson 6’s Exercise 10 proved the same thing by building the mediating arrows by hand; here they are never mentioned.

A law of exponents. In Set, for any X,

Set(X, YA + B)  ≅  Set(X × (A + B), Y)  ≅  Set(X × A + X × B, Y)

≅  Set(X × A, Y) × Set(X × B, Y)  ≅  Set(X, YA × YB).

In order: currying; the fact that X × (−), a left adjoint, preserves coproducts; the universal property of the coproduct; then currying twice and the universal property of the product. So YA + B ≅ YA × YB, with no element in sight. The same chain proves the law in any category that has the constructions it mentions.

This style of argument — reduce a statement about objects to a statement about sets of arrows, and do the work there — is the everyday use of the Yoneda lemma. Lesson 8 used it once already, in the second proof that right adjoints preserve limits.

§5 — Universal properties are representations

One statement behind three lessons

Return to the coincidence of §1. A representation of a presheaf F is a natural isomorphism yA ≅ F. By the Yoneda lemma, any natural transformation yA ⇒ F is given by a single element of F(A). So a representation must be given by a single element too — an element with a special property.

Definition · Universal element

Let F be a presheaf on 𝒞. A universal element of F is a pair (A, u), with A an object and u ∈ F(A), such that for every object X and every element x ∈ F(X) there is exactly one arrow f : X → A with F(f)(u) = x. For a covariant functor F : 𝒞 → Set the arrow goes the other way, f : A → X, and the condition is again F(f)(u) = x.

Theorem · Representations are universal elements

Let u ∈ F(A), and let α : yA ⇒ F be the natural transformation belonging to it. Then α is a natural isomorphism if and only if (A, u) is a universal element.

Proof. A natural transformation is an isomorphism exactly when each of its components is a bijection (Lesson 3). The component at X is the function f ↦ F(f)(u) from 𝒞(X, A) to F(X). It is a bijection exactly when each x ∈ F(X) is F(f)(u) for one and only one f. ∎

“For every competitor there is exactly one arrow such that…” — that is the form of every universal property in this course. The theorem says that the form has a meaning: to state a universal property is to exhibit a universal element of some functor, and so to represent it. Here is the dictionary.

The uniqueness theorems of Lessons 6, 7 and 8 now have a single proof.

Corollary · Universal objects are unique

If (A, u) and (B, v) are universal elements of the same presheaf F, there is exactly one arrow f : A → B with F(f)(v) = u, and it is an isomorphism.

Proof. Universality of v, applied to the element u ∈ F(A), gives exactly one f : A → B with F(f)(v) = u. Universality of u gives exactly one g : B → A with F(g)(u) = v. Then F(f ∘ g)(v) = F(g)(F(f)(v)) = F(g)(u) = v = F(idB)(v), so f ∘ g = idB, since only one arrow B → B carries v to v. In the same way g ∘ f = idA. ∎

It is the argument of Lesson 6 once more, and for the last time: it has now been carried out for every universal construction at once. In the language of §4 it is even shorter. Both yA and yB are isomorphic to F, hence to each other, and the Yoneda embedding reflects isomorphisms.

Limits and adjoints, restated

Two promises from earlier lessons can now be kept.

Limits. Lesson 7 showed that an arrow into a limit of D is the same thing as a cone, and said that this property characterises the limit. Precisely: the cones over D form a presheaf X ↦ Cone(X, D) — an arrow g : X → Y turns a cone with apex Y into one with apex X by composing each leg with g — and

a limit of D  is  a representation of the presheaf of cones over D.

One direction is Lesson 7’s theorem. The other is the theorem above: if 𝒞(X, L) ≅ Cone(X, D) naturally in X, then the cone corresponding to idL is a universal element, which is to say a limit cone. This is the step that Lesson 8 postponed in its second proof that right adjoints preserve limits. There, a chain of natural bijections showed 𝒞(X, U L) ≅ Cone(X, U ∘ D); the cone corresponding to the identity of U L works out to be U λ; and so U λ is a limit cone.

Adjoints. A functor U : 𝒟 → 𝒞 has a left adjoint exactly when, for every object X of 𝒞, the functor 𝒞(X, U −) : 𝒟 → Set is representable. That is the theorem on universal arrows of Lesson 8 in the vocabulary of this one, and the representing object is F X.

So the single notion of a representable functor accounts for all three lessons. A category has products when certain presheaves are representable; it has limits when the presheaves of cones are; a functor has a left adjoint when certain functors built from it are. In each case the Yoneda lemma guarantees that the representing object, if there is one, is unique up to a unique isomorphism — and that nothing about it is left undetermined.

§6 — Yoneda by hand

Count the natural transformations

The lemma makes a prediction every time it is applied: a count of natural transformations. In small cases the count can be checked directly.

An element is its down-set

In the divisibility order on the divisors of 12 the representable presheaves are the down-sets:

a1234612
↓a{1}{1, 2}{1, 3}{1, 2, 4}{1, 2, 3, 6}all six

The six down-sets are different, so the element can be recovered from its down-set: it is the largest member. And the order can be recovered too: a divides b exactly when ↓a ⊆ ↓b. For instance 4 divides 12 and ↓4 ⊆ ↓12, while 4 does not divide 6 and {1, 2, 4} is not contained in {1, 2, 3, 6}. That is the Yoneda embedding for this order: it is isomorphic to a family of subsets ordered by inclusion. The same is true of every poset, by the same argument.

Twenty-seven candidates, three survivors

Let 𝒞 be the one-object category of the group ℤ/3 under addition. A natural transformation from y∗ to itself is a function α from {0, 1, 2} to itself with

α(f + g) = α(f) + g     for all f and g.

There are 33 = 27 functions to consider. Put f = 0: the condition gives α(g) = α(0) + g. So α is known as soon as α(0) is, and there are three choices for that. Each choice works: if α(g) = c + g, then α(f + g) = c + f + g = α(f) + g. So exactly three of the 27 functions are natural — “add 0,” “add 1” and “add 2” — one for each arrow of the category, as the lemma predicts: Nat(y∗, y∗) ≅ 𝒞(∗, ∗).

Cayley’s theorem

The same computation for an arbitrary group G proves a classical theorem. Regard G as a one-object category. The Yoneda embedding sends its one object to the set G, with G acting on the right, and sends each element a to the equivariant map “multiply by a on the left.” Since the embedding is full and faithful, and functors preserve inverses, G is isomorphic to the group of all equivariant bijections of the set G — a group of permutations.

Theorem · Cayley

Every group is isomorphic to a group of permutations of a set: namely of its own underlying set, with a acting as x ↦ a x.

For ℤ/3 the three permutations of {0, 1, 2} are the identity and the two cyclic shifts. The theorem goes back to Cayley’s paper of 1854, a century before Yoneda’s lemma — of which it is the special case of a category with one object. For a monoid the same argument gives an embedding into the monoid of all functions from a set to itself.

Graphs, counted

Let G be the graph with vertices p, q, r and edges a : p → q, b : q → r, c : q → q, d : p → r.

A homomorphism from the lone edge yE to G must send its edge to one of a, b, c, d, and the images of its two vertices are then forced — for c, both vertices go to q. So there are four homomorphisms, one for each edge of G. From the lone vertex yV there are three, one for each vertex. Those are the two instances of the lemma for this graph: Nat(yE, G) ≅ G(E) and Nat(yV, G) ≅ G(V).

Natural operations on pairs

How many natural transformations are there from the squaring functor X ↦ X × X to the cubing functor X ↦ X × X × X on Set? They are represented by a two-element set and a three-element set, so by the covariant Yoneda lemma the natural transformations Set(2, −) ⇒ Set(3, −) correspond to elements of Set(3, 2): functions from a three-element set to a two-element set. There are 23 = 8. Each one says which of the two inputs to copy into each of the three output positions: for instance (x, y) ↦ (x, x, y), or (x, y) ↦ (y, y, y). Notice the direction: a natural transformation from the functor represented by 2 to the functor represented by 3 comes from a function 3 → 2. The covariant embedding A ↦ 𝒞(A, −) is contravariant.

Optional · PythonYoneda, counted by machine

yoneda_poset.py — an element is its down-set

    for b in objs:
        assert (b % a == 0) == (downset[a] <= downset[b])  # a|b iff ds(a) ⊆ ds(b)

Third, a category that is not thin and has more than one object: the category 𝒢 whose presheaves are graphs. The code below represents a presheaf by its sets and its restriction functions, builds the representables from the definition, and counts natural transformations by trying every family of functions.

presheaves.py — presheaves on a finite category, and maps between them
from itertools import product as cartesian

# the category  V ==s,t==> E ;  ar[name] = (source, target)
objs = ['V', 'E']
ar   = {'iV': ('V', 'V'), 'iE': ('E', 'E'),
        's':  ('V', 'E'), 't':  ('V', 'E')}
comp = {('iV', 'iV'): 'iV', ('iE', 'iE'): 'iE', ('s', 'iV'): 's',
        ('t', 'iV'): 't', ('iE', 's'): 's', ('iE', 't'): 't'}

def hom(X, A):
    "the arrows X -> A"
    return [h for h, (d, c) in ar.items() if d == X and c == A]

class Presheaf:
    "sets[X] is F(X);  act[g] is F(g) : F(Y) -> F(X)  for  g : X -> Y"
    def __init__(self, sets, act):
        self.sets, self.act = sets, act

def y(A):
    "the representable presheaf: arrows into A, acting by precomposition"
    sets = {X: hom(X, A) for X in objs}
    act  = {g: {h: comp[(h, g)] for h in sets[c]}
            for g, (d, c) in ar.items()}
    return Presheaf(sets, act)

def nat(F, G):
    "all natural transformations F => G, by exhaustive search"
    def functions(X):
        dom, cod = F.sets[X], G.sets[X]
        return [dict(zip(dom, vals))
                for vals in cartesian(cod, repeat=len(dom))]
    out = []
    for fam in cartesian(*[functions(X) for X in objs]):
        alpha = dict(zip(objs, fam))
        if all(alpha[d][F.act[g][e]] == G.act[g][alpha[c][e]]
               for g, (d, c) in ar.items() for e in F.sets[c]):
            out.append(alpha)
    return out

print("yV:", y('V').sets, "  yE:", y('E').sets)

Going deeper

Every presheaf is glued from representables

The graphs yV and yE are more than examples. Any graph can be assembled from copies of them: take one copy of the lone vertex for each vertex, one copy of the lone edge for each edge, and glue the ends of the edges to the vertices as the source and target functions direct. Gluing is what colimits do (Lesson 7), so every graph is a colimit of representables.

The same is true of presheaves on any small category 𝒞.

Theorem · Density

Every presheaf F on a small category is a colimit of representable presheaves: one copy of yA for each element of each set F(A), glued along the arrows of 𝒞.

The Yoneda lemma is what makes the statement plausible. An element a ∈ F(A) is a map yA ⇒ F, so the elements of F are exactly the ways of mapping the representables into it, and F is covered by the images of those maps. The theorem adds that nothing more than the evident gluing is needed. The diagram being glued is indexed by a category you have met: its objects are the pairs (A, a) with a ∈ F(A), a comma category in the sense of Lesson 5, usually called the category of elements of F.

So the representables play the role in a presheaf category that the one-element set plays in Set, where every set is a coproduct of copies of 1: they are the building blocks, and the Yoneda lemma says how to map out of a building block. Two facts complete the picture. A presheaf category has all limits and colimits, computed one object at a time in Set. And the Yoneda embedding preserves whatever limits 𝒞 has — that is Lesson 7’s theorem that hom functors preserve limits — but not, in general, its colimits (Exercise 8). The embedding therefore places 𝒞 inside a category in which every colimit exists and none of the new ones has been identified with anything that was there before. In that sense the presheaf category is the free cocompletion of 𝒞; it is the starting point of topos theory, and of much of the modern use of categories in geometry and logic.

Exercise 1by hand

Representable or not? For each functor Set → Set, either name a set that represents it or explain why none can.

  1. The identity functor.
  2. X ↦ X × X × X.
  3. X ↦ X + 1, which adds one new element.
  4. X ↦ XA, for a fixed set A.
  5. The constant functor whose value is a one-element set.
  6. The constant functor whose value is a two-element set.
Show solution

The test of §2: a representable functor Set(A, −) sends a one-element set to a one-element set, since there is exactly one function from A to a one-element set.

(a) Represented by a one-element set. (b) Represented by a three-element set: a function 3 → X is a triple of elements. (c) Not representable: its value at a one-element set has two elements. (d) Represented by A — by definition, XA is the set Set(A, X). (e) Represented by the empty set: for every X there is exactly one function ∅ → X. (f) Not representable: its value at a one-element set has two elements.

Part (e) is easy to get wrong. The constant functor at 1 looks as if it “remembers nothing,” and it is represented by the object from which there is always exactly one arrow: the initial one.

Exercise 2structure

Complete the surjectivity half of the Yoneda proof. Given a presheaf F and an element a ∈ F(A), define the family αX(f) = F(f)(a) for f : X → A.

Verify the two things §3 left to you: that each naturality square of α commutes (use the functoriality of F — mind the contravariance), and that tracking the identity recovers a: αA(idA) = a.

Show solution

Naturality. Fix g : X → Y. The square requires αX(f ∘ g) = F(g)(αY(f)) for every f : Y → A — precompose first or apply F(g) after. Left side: F(f ∘ g)(a). Right side: F(g)(F(f)(a)). These agree because F, being contravariant, sends f ∘ g to F(g) ∘ F(f) — the flip of Lesson 2’s composition law is exactly what the square needs. (Had F been covariant, the square would demand the un-flipped law; the variance and the direction of translation are made for each other.)

Recovery. αA(idA) = F(idA)(a) = idF(A)(a) = a, by the identity law of F. So “element to transformation to element” is the identity — one of the two round trips of the bijection; §3’s determination argument was the other. Both functor laws of Lesson 2 were consumed, one per round trip, with nothing left over.

Exercise 3arrows-only

The Yoneda bijection is natural in A. Let F be a presheaf, h : A → B an arrow, and β : yB ⇒ F a natural transformation belonging to the element b ∈ F(B). Show that the composite β ∘ y(h) : yA ⇒ F belongs to the element F(h)(b) of F(A).

Show solution

The element belonging to a transformation out of yA is its value at idA. The component of y(h) at A sends idA to h ∘ idA = h, an element of yB(A). Then βA(h) = F(h)(b), by the formula βX(f) = F(f)(b) of §3 with X = A and f = h. So (β ∘ y(h))A(idA) = F(h)(b).

In a square: going from Nat(yB, F) to F(B) and then applying F(h) is the same as first composing with y(h) and then going from Nat(yA, F) to F(A). The two sides of the Yoneda lemma are not merely sets of the same size for each A; they are naturally isomorphic presheaves.

Exercise 4duality

State the covariant Yoneda lemma — for functors 𝒞 → Set and the co-representable 𝒞(A, −), arrows out of A — by dualizing everything in §3. What does the corollary become, as a slogan?

Show solution

For any covariant F : 𝒞 → Set: Nat(𝒞(A, −), F) ≅ F(A), again via α ↦ αA(idA), with translation now by postcomposition and the determining formula αX(f) = F(f)(a) using F’s covariance. Formally it is §3’s lemma applied to 𝒞op — the duality principle of Lesson 5, at work once more.

Slogan: an object is also the arrows out of it. Both dossiers are complete; you may know an object by how everything probes it, or by how it probes everything. (In the poset shadow: an element is determined by its down-set, and equally by its up-set.)

Exercise 5counting

Count natural transformations with the covariant Yoneda lemma (Exercise 4). Write S for the squaring functor X ↦ X × X on Set, represented by a two-element set. Find all natural transformations, and describe each one:

  1. S ⇒ Id;
  2. Id ⇒ S;
  3. S ⇒ S;
  4. S ⇒ P, where P is the covariant power set functor.
Show solution

In each case Nat(Set(A, −), F) ≅ F(A), and the transformation belonging to a ∈ F(A) sends a function f : A → X to F(f)(a).

(a) Id(2) has two elements, 0 and 1. The transformation belonging to i sends a pair (x0, x1), that is, a function 2 → X, to xi. So there are two: the projections.

(b) Id is represented by 1, and S(1) = 1 × 1 has one element. So there is one: the diagonal x ↦ (x, x).

(c) S(2) = 2 × 2 has four elements (i, j), giving (x0, x1) ↦ (xi, xj): the identity, the swap, and the two maps (x0, x1) ↦ (x0, x0) and (x0, x1) ↦ (x1, x1).

(d) P(2) has four elements, the subsets of {0, 1}. They give (x0, x1) ↦ ∅, ↦ {x0}, ↦ {x1} and ↦ {x0, x1}.

None of these lists is surprising. What the lemma adds is that they are complete: there is no fifth natural way to turn a pair of elements into a set of elements.

Exercise 6think

Natural operations on groups. Let U : Grp → Set be the forgetful functor, represented by ℤ.

  1. Use the covariant Yoneda lemma to show that natural transformations U ⇒ U correspond to integers.
  2. Which natural transformation belongs to the integer n? Track the identity.
  3. Conclude that every operation x ↦ αG(x), defined on the elements of all groups at once and commuting with all homomorphisms, is a power map. Which integers give inversion and squaring?
  4. What is the answer for monoids?
Show solution

(a) Nat(U, U) ≅ Nat(Grp(ℤ, −), U) ≅ U(ℤ), the set of integers.

(b) Under the representation, an element x of a group G corresponds to the homomorphism hx : ℤ → G with hx(1) = x, that is, hx(k) = xk. The transformation belonging to n ∈ U(ℤ) sends a homomorphism h to U(h)(n) = h(n). On elements: x ↦ hx(n) = xn.

(c) So the natural transformations U ⇒ U are exactly the maps x ↦ xn, one for each integer n: inversion is n = −1 and squaring is n = 2. A component αG is a function on the underlying set and need not be a homomorphism — squaring is one only in an abelian group — but it commutes with every homomorphism, which is what naturality asks.

(d) For monoids U is represented by ℕ, so the natural operations are the powers x ↦ xn with n ≥ 0. Inversion has disappeared, as it should.

The moral reaches well beyond groups. An operation that makes sense for every structure of a given kind, uniformly, can be written in the language of that structure — and the Yoneda lemma is the proof.

The Yoneda embedding

§4 · Exercises 7–10

Exercise 7warm-up

In the divisibility order on {1, 2, 3, 6}, write out the four down-sets by hand and verify, for the three pairs (2, 6), (2, 3), and (6, 6), the Yoneda biconditional: a | b exactly when downset(a) ⊆ downset(b).

Then say in one sentence why no two distinct elements of a poset can ever have the same down-set.

Show solution

The down-sets: {1}, {1,2}, {1,3}, {1,2,3,6} — the ones the lab in §6 prints. Pairs: 2 | 6 and {1,2} ⊆ {1,2,3,6} ✓; 2 ∤ 3 and {1,2} ⊄ {1,3} ✓; 6 | 6 and equality of sets ✓.

If downset(a) = downset(b), then since a ∈ downset(a) we get a ∈ downset(b), i.e. a ≤ b, and symmetrically b ≤ a — so a = b by antisymmetry (or a ≅ b in a preorder). Note the proof’s engine: the element belongs to its own down-set because of the identity arrow a ≤ a. Even in this baby case, the identity is the tracked probe — the thin-category shadow of the Yoneda proof.

Exercise 8examples

The embedding preserves limits, not colimits. Work in the divisibility order on {1, 2, 3, 6}, with presheaves regarded as down-closed subsets, as in §3.

  1. The product of 2 and 3 is their meet. Check that ↓(2 ∧ 3) = ↓2 ∩ ↓3.
  2. The coproduct of 2 and 3 is their join. Show that ↓(2 ∨ 3) is not ↓2 ∪ ↓3.
  3. List all the down-closed subsets. Which are not representable?
Show solution

(a) 2 ∧ 3 = 1 and ↓1 = {1}; and {1, 2} ∩ {1, 3} = {1}.

(b) 2 ∨ 3 = 6 and ↓6 = {1, 2, 3, 6}, but {1, 2} ∪ {1, 3} = {1, 2, 3}.

(c) There are six: ∅, {1}, {1, 2}, {1, 3}, {1, 2, 3} and {1, 2, 3, 6}. Four are down-sets of elements. The other two, ∅ and {1, 2, 3}, are not representable.

Among the down-closed subsets, ordered by inclusion, the join of ↓2 and ↓3 is their union {1, 2, 3} — a new element, strictly below ↓6. So the embedding keeps the meets of the original order but does not keep its joins: it supplies fresh ones, and a fresh bottom element ∅ as well. This is the free cocompletion of the Going-deeper section, small enough to draw.

Exercise 9arrows-only

Write out in full the two corollaries that §4 drew from the lemma:

  1. Setting F = yB, show Nat(yA, yB) ≅ 𝒞(A, B), and describe explicitly which transformation an arrow h : A → B becomes.
  2. Conclude that y is fully faithful, and that yA ≅ yB (in the presheaf category) implies A ≅ B (in 𝒞).
Show solution

(a) The lemma with F = yB reads Nat(yA, yB) ≅ yB(A) = 𝒞(A, B). Chasing the bijection: the element h ∈ 𝒞(A, B) becomes the transformation with components αX(f) = yB(f)(h) = h ∘ f — postcomposition by h. That is exactly what the census of §6 found: all three survivors were postcompositions, one per arrow.

(b) The bijection is precisely the statement that y is full (surjective on hom-sets) and faithful (injective) — one checks it also respects composition, which is associativity of ∘. A fully faithful functor reflects isomorphisms: if α : yA ≅ yB, write α = y(h) and α−1 = y(k); then y(k ∘ h) = y(k) ∘ y(h) = id = y(idA), and faithfulness cancels the y, giving k ∘ h = idA, likewise h ∘ k = idB. So A ≅ B — the slogan, fully proved, using only machinery this course built.

Exercise 10arrows-only

Isomorphisms by Yoneda (§4). In a category with binary products and a terminal object 1, prove each of the following by computing the arrows into both sides from an arbitrary object X.

  1. A × B ≅ B × A.
  2. A × 1 ≅ A.
  3. In Set: (YA)B ≅ YA × B.
Show solution

(a) 𝒞(X, A × B) ≅ 𝒞(X, A) × 𝒞(X, B) ≅ 𝒞(X, B) × 𝒞(X, A) ≅ 𝒞(X, B × A). The outer steps are the universal property of the product, and the middle step swaps the two entries of a pair of arrows. All three are natural in X.

(b) 𝒞(X, A × 1) ≅ 𝒞(X, A) × 𝒞(X, 1) ≅ 𝒞(X, A), because 𝒞(X, 1) has exactly one element, and pairing with a fixed element is a bijection.

(c) Set(X, (YA)B) ≅ Set(X × B, YA) ≅ Set((X × B) × A, Y) ≅ Set(X × (A × B), Y) ≅ Set(X, YA × B): currying twice, then the associativity and symmetry of the product, then currying backwards. Counted, this is (ya)b = ya b.

Lesson 6 proved (b) directly (Lesson 6, Exercise 9), and the associativity of products too (Lesson 6, Exercise 10), by constructing mediating arrows and checking that they are inverse. Here no arrow between the two objects is ever written down: the Yoneda embedding manufactures the isomorphism from the bijections.

Universal elements

Exercise 11by hand

A universal element, examined. The contravariant power set functor sends a set X to the set P(X) of its subsets and a function to its inverse-image map. §2 said that it is represented by a two-element set, 2 = {0, 1}.

  1. Let X = {a, b, c} and S = {a, c}. Find all functions χ : X → 2 with χ−1({1}) = S.
  2. Explain why (a), done for every X and S, says that (2, {1}) is a universal element of P.
  3. Is (2, {0}) also a universal element? Is (3, {1}), where 3 = {0, 1, 2}?
Show solution

(a) There is exactly one: χ(a) = 1, χ(b) = 0, χ(c) = 1. The condition says that χ(x) = 1 exactly when x ∈ S, which fixes every value.

(b) The element in question is u = {1}, a member of P(2). For a function χ : X → 2, the map P(χ) is inverse image, so P(χ)(u) = χ−1({1}). Universality asks that every element S of P(X) be P(χ)(u) for exactly one χ, and that is what (a) shows.

(c) (2, {0}) is universal too: the unique χ is now the one that sends the elements of S to 0. The two universal elements are related by a unique isomorphism, as the corollary of §5 says they must be — the function 2 → 2 that swaps 0 and 1. But (3, {1}) is not universal. Existence is fine; uniqueness fails, since an element outside S may be sent to 0 or to 2. For S = {a, c} and X = {a, b, c} there are two functions with the right inverse image.

Exercise 12structure

Extend the dictionary of §5. For each object, say which functor it represents — give its value at an arbitrary X, and say whether it is a presheaf or covariant — and name the universal element.

  1. The pullback of f : A → Z and g : B → Z.
  2. The coequalizer of f, g : A → B.
  3. The free monoid on a set S, as an object of Mon.
  4. The meet a ∧ b of two elements of a poset.
Show solution

(a) A presheaf: X goes to the set of pairs (x, y) with x : X → A, y : X → B and f ∘ x = g ∘ y. The universal element is the pair of projections (p1, p2) of the pullback.

(b) Covariant: X goes to the set of arrows q : B → X with q ∘ f = q ∘ g. The universal element is the coequalizer arrow itself.

(c) Covariant, on Mon: a monoid M goes to the set of functions S → U M. The universal element is the function s ↦ [s], the unit of the adjunction.

(d) A presheaf with values empty or one-element: it is inhabited at x when x ≤ a and x ≤ b. As a down-closed set it is the intersection ↓a ∩ ↓b. It is representable exactly when that intersection is the down-set of a single element — and that element is the meet. The universal element is the pair of facts a ∧ b ≤ a and a ∧ b ≤ b.

Cayley, for a monoid and for a group.

  1. Let M be the monoid {0, 1} under multiplication. List the four functions α : M → M and decide which satisfy α(m n) = α(m) n for all m, n. How many does the Yoneda lemma predict?
  2. Identify each survivor as “multiply on the left by a.”
  3. For the group ℤ/4 under addition, write down the four permutations of {0, 1, 2, 3} that Cayley’s theorem assigns to its elements. What fraction of all permutations of a four-element set are they?

  2. How many natural transformations y∗ ⇒ S does the Yoneda lemma predict? Describe them.

Optional · Python

Confirm both counts by exhaustive search: over the 63 = 216 functions ℤ/3 → S, and the 36 = 729 functions S → ℤ/3.

Show solution

By hand. (a) Acting by 0 adds nothing. Acting by g and then by h adds 2g + 2h, and acting by g + h (reduced modulo 3) adds 2(g + h) or 2(g + h) − 6 — the same modulo 6.

(b) Nat(y∗, S) ≅ S, so six. The transformation belonging to s sends g to s · g = s + 2g.

(c) S falls into two orbits, the even numbers and the odd ones. On the even orbit, β(2g) = β(0) + g, so β is determined there by β(0); on the odd orbit, β(1 + 2g) = β(1) + g, so it is determined by β(1). The two values can be chosen independently, three ways each, and every choice gives a natural transformation: 3 × 3 = 9.

The count in (c) has a Yoneda explanation after all. Each orbit, with the action, is a copy of y∗, so S is a coproduct of two representables. A map out of a coproduct is a pair of maps, and Nat(y∗, y∗) has three elements: 32 = 9. Every presheaf can be taken apart into representables in this way — that is the density theorem — though usually with gluing as well as disjoint union.

Optional · Python
orbits.py — equivariant maps, both ways
from itertools import product as cartesian

Z3, S = range(3), range(6)
act = lambda s, g: (s + 2 * g) % 6          # the action of Z/3 on S

into_S = [a for a in cartesian(S, repeat=3)             # a[f] = alpha(f)
          if all(a[(f + g) % 3] == act(a[f], g)
                 for f in Z3 for g in Z3)]
out_of_S = [b for b in cartesian(Z3, repeat=6)          # b[s] = beta(s)
            if all(b[act(s, g)] == (b[s] + g) % 3
                   for s in S for g in Z3)]
print("y* => S :", len(into_S), "of", 6 ** 3)
print("S => y* :", len(out_of_S), "of", 3 ** 6)
outputy* => S : 6 of 216 S => y* : 9 of 729
Recap

What to carry forward

  1. A presheaf on 𝒞 is a functor 𝒞op → Set: a structure made of sets, shaped by 𝒞. Directed graphs are the presheaves on a category with two objects. Each object A gives the presheaf yA = 𝒞(−, A) of arrows into it.
  2. The Yoneda lemma: Nat(yA, F) ≅ F(A). A transformation α goes to αA(idA), and an element a goes to the transformation f ↦ F(f)(a). The proof is one naturality square: track the identity.
  3. The Yoneda embedding A ↦ yA is full and faithful, so A ≅ B if and only if yA ≅ yB: an object is the arrows into it — and, dually, the arrows out of it. In a poset an element is its down-set; for a group this is Cayley’s theorem.
  4. A functor is representable when it is naturally isomorphic to a hom functor, and a representation is the same thing as a universal element. Terminal objects, products, limits, exponentials, free objects and adjoints are all representing objects, and all unique for one and the same reason.
  5. To prove two objects isomorphic, compute the arrows into each from an arbitrary X and compare, naturally in X.
  6. In finite cases the lemma predicts numbers that can be checked: 3 natural maps among 27 candidates for ℤ/3; as many homomorphisms out of the lone edge as a graph has edges.
