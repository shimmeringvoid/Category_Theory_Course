§1 — The reflex

New objects? Ask for the maps

Lesson 1 handed us a new kind of mathematical object: the category. Category theory now does what it always does when it meets a new object — it asks for the right notion of map between them, the maps that respect whatever structure those objects carry.

A category’s structure is exactly four things: objects, arrows, identities, and composition. So a map of categories ought to send objects to objects and arrows to arrows, and leave identities and composition intact. That map is a functor, and pinning it down is the whole job of this lesson.

Functors are not exotic. “Build a list of,” “take the underlying set of,” “form the free group on,” “the fundamental group of a space” — every one of these is a functor. In code, every lawful map is a functor. They are how one region of mathematics gets translated into another, and the translation is faithful enough to carry whole theorems across the bridge.

§2 — The definition

Two assignments, two laws

The shape of the definition should feel familiar — it mirrors Lesson 1 line for line.

Definition · Functor

A functor F : 𝒞 → 𝒟 consists of:

  • an object map — to each object X of 𝒞, an object F X of 𝒟
  • an arrow map — to each arrow f : X → Y, an arrow F f : F X → F Y

satisfying:

IdentitiesF(idX) = idF X
CompositionF(g ∘ f) = F g ∘ F f

Mind the typing. The arrow map isn’t free to send f anywhere — F f must run from F X to F Y. A functor therefore transports an entire diagram in 𝒞 to a same-shaped diagram in 𝒟: whatever picture you draw in the source, F redraws it in the target with every dot and arrow relabelled. That is exactly what the triangle at the top of the page shows.

The laws are not arbitrary. They say: preserve the two things that made 𝒞 a category in the first place. Identities and composites are the structure; a functor is precisely a map of objects-and-arrows that keeps them.

Aside · Contravariance

Some natural constructions reverse arrows rather than preserving them. A contravariant functor sends f : X → Y to an arrow F f : F Y → F X and obeys F(g ∘ f) = F f ∘ F g. The everyday example: fix a set S and send each set X to the set of functions X → S; a map f : X → Y then induces “precompose with f” running the other way, (Y → S) → (X → S). The default kind is covariant; contravariant just flips every arrow. The systematic source of this is the opposite category of Lesson 1, Exercise 7; the Going-deeper section below makes the connection.

§3 — What a functor guarantees

It can forget distinctions, but never invent them

Because a functor preserves composition and identities, it sends commuting diagrams to commuting diagrams: if two paths in 𝒞 are equal, their F-images are equal. A functor can never break an equation between composites — at worst it collapses things that were different, but it cannot pull apart things that were the same. From this single observation comes the first real theorem of the lesson.

Theorem · Functors preserve isomorphisms

If f : X → Y is an isomorphism — there is g : Y → X with g ∘ f = idX and f ∘ g = idY — then F f is an isomorphism too, with inverse F g.

Proof (arrows only). Apply F to g ∘ f = idX. Composition-preservation turns the left side into F g ∘ F f, and identity-preservation turns the right side into idF X, so F g ∘ F f = idF X. The symmetric computation gives F f ∘ F g = idF Y. Hence F g is a two-sided inverse of F f. ∎

Run that backwards and you get one of the most productive moves in mathematics. If some functor F sends X and Y to objects that are not isomorphic, then X and Y could not have been isomorphic either. The classic instance is the fundamental group π1 : Top∗ → Grp: a circle and a disk have different fundamental groups, so they are not the same space. Functors convert a hard question — are these spaces the same? — into an easier one about groups.

One caution, so the guarantee isn’t oversold: functors preserve isomorphisms but need not reflect them — F f being an iso does not force f to be one — and they need not preserve unrelated features like injectivity. The promise runs one direction only.

§4 — A gallery of functors

Eight functors, and one of them is the subject eating its own tail

i. The identity functor, composition, and Cat

Every category 𝒞 has an identity functor id𝒞 fixing every object and arrow. And functors compose: given F : 𝒞 → 𝒟 and G : 𝒟 → ℰ, the assignment X ↦ G(F X), f ↦ G(F f) is again a functor — it preserves identities and composition because F and G each do. Functor composition is associative; identity functors are units. Read that back: it is the Lesson 1 definition of a category, with categories as objects and functors as arrows. That category is called Cat. (To stay clear of the size paradoxes in Lesson 1’s footnote, its objects are taken to be the small categories.) We have climbed a floor — the thing we defined last lesson is itself an example of the thing we defined last lesson.

ii. Forgetful functors

The functor U : Grp → Set sends a group to its underlying set and a homomorphism to its underlying function — it simply forgets the multiplication. It qualifies as a functor for an almost embarrassing reason: a homomorphism already is a function, and composing or taking identities of homomorphisms is composing or taking identities of those functions. The same move gives Vect → Set, Top → Set, Ring → Ab, and dozens more. Forgetting structure is the most common functor in the wild.

iii. Free functors

Going the other way — building the freest possible structure on raw material — is where it gets interesting. Set → Mon sends a set A (an “alphabet”) to the free monoid on it: finite sequences of elements of A under concatenation, with the empty sequence as unit. That is exactly strings, exactly lists. A function between alphabets lifts to the map that rewrites each sequence letter by letter. Free and forgetful functors travel in matched pairs — an adjunction — which is the summit this course is climbing toward.

iv. Maps you already knew, in disguise

Recall from Lesson 1 that a one-object category is a monoid. A functor between two one-object categories must send the lone object to the lone object, and its arrow map is then a function on elements that preserves composition (the operation) and the identity (the unit) — i.e. a monoid homomorphism. Likewise a functor between two preorders-as-categories is forced to send the arrow witnessing x ≤ y to one witnessing F x ≤ F y, which is exactly a monotone function. Two familiar notions of “map” turn out to be the single notion “functor,” specialised.

v. Small categories as shapes

A functor 𝟙 → 𝒞 is a choice of an object of 𝒞 — the single object has to land somewhere. A functor 𝟚 → 𝒞 is a choice of an arrow: the non-identity arrow 0 → 1 must go to some arrow, and everything else is forced. This is the precise form of the teaser from Lesson 1. Tiny categories act as templates, and functors out of them pick that shape out inside any target — bigger shapes will pick out commuting squares, parallel pairs, and cones, which become the raw material of limits in Lesson 7.

vi. The List functor, concretely

On the category of types, List sends a type A to List[A] and a function f : A → B to the function that applies f to every element. Its two functor laws — map(id) == id and map(g ∘ f) == map(g) ∘ map(f) — are exactly the laws every well-behaved map must obey, and they are why a compiler is permitted to fuse map(g) ∘ map(f) into a single pass. The optional Python lab in §7 makes all of this run.

vii. Actions: functors from a monoid to Set

Let M be a monoid, viewed as a one-object category. What is a functor F : M → Set? The single object must go to some set S. Each arrow — each element m of M — must go to a function F(m) : S → S. The functor laws say F(e) = idS and F(m · n) = F(m) ∘ F(n). That is precisely the classical notion of M acting on the set S: every element of the monoid moves the points of S around, compatibly with multiplication.

Two instances are worth carrying with you. A functor from (ℕ, +) to Set is determined by the single function t = F(1), because F(n) = t ∘ ⋯ ∘ t (n times): so it is nothing more than a set with a function from the set to itself — a system with a clock, where t is “advance one tick.” And a functor from a group G to Vect is a group acting by linear maps: a linear representation of G. An entire field, representation theory, is the study of functors out of a group.

viii. Functors built from products

Fix a set A. Sending each set X to the product X × A is the object map of a functor (−) × A : Set → Set; on arrows it sends f : X → Y to the function f × idA that takes (x, a) to (f(x), a). The laws can be checked at a glance — idX × idA fixes every pair, and applying f and then g in the first coordinate is applying g ∘ f there. This functor returns in Lesson 8 as one half of the most familiar adjunction in programming. A cousin lives on any category with enough structure to form pairs, and one variant needs no structure at all: the diagonal functor Δ : 𝒞 → 𝒞 × 𝒞 into the product category of Lesson 1, Exercise 12, with Δ X = (X, X) and Δ f = (f, f).

§5 — Hom functors

The two functors every object carries for free

So far each functor needed a construction. But every category comes with a supply of functors built from nothing but its own arrows, and they turn out to be the most important of all. Assume from here on that 𝒞 is locally small, so that the arrows between two objects form a set 𝒞(X, Y).

Definition · The covariant hom functor

Fix an object A of 𝒞. The functor 𝒞(A, −) : 𝒞 → Set sends

  • each object X to the set 𝒞(A, X) of arrows from A to X;
  • each arrow f : X → Y to the function 𝒞(A, X) → 𝒞(A, Y) given by composing with f: h ↦ f ∘ h.

Why is this a functor? The identity law requires that composing with idX do nothing: idX ∘ h = h. The composition law requires that composing with g ∘ f equal composing with f and then with g: (g ∘ f) ∘ h = g ∘ (f ∘ h). These are exactly the identity law and the associativity law of 𝒞. The two functor laws for 𝒞(A, −) are the two category laws of 𝒞 — the definition of a category could hardly be better fitted to making this work.

Arrows into a fixed object behave the same way, with one twist. An arrow f : X → Y converts arrows Y → A into arrows X → A by composing on the other side, h ↦ h ∘ f — and now the conversion runs from 𝒞(Y, A) to 𝒞(X, A), against the direction of f. So arrows into A form a contravariant functor in the sense of §2’s aside, written 𝒞(−, A).

Six hom functors by hand

  1. Elements. In Set, let 1 be a one-element set. A function 1 → X is a choice of one element of X, so Set(1, X) is a copy of X itself, and composing with f becomes applying f. The functor Set(1, −) is the identity functor in disguise.
  2. Pairs. Let 2 = {0, 1}. A function 2 → X is an ordered pair (x0, x1) of elements of X, so Set(2, X) is a copy of X × X, and composing with f sends (x0, x1) to (f(x0), f(x1)).
  3. Subsets. A function X → 2 is the same thing as a subset of X: the elements sent to 1. So Set(X, 2) is a copy of the powerset of X, and — check it — composing with f : X → Y on the right turns a subset T of Y into its inverse image f−1(T). The contravariant powerset functor of the Going-deeper section is a hom functor.
  4. Order. In a preorder, 𝒞(a, x) has one element when a ≤ x and none otherwise. So 𝒞(a, −) simply records which elements lie above a, and 𝒞(−, a) which lie below. The table shows the size of 𝒞(a, x) in the divisibility order on {1, 2, 3, 6}:
    a \ x1236
    11111
    20101
    30011
    60001
    Read along a row for the covariant functor 𝒞(a, −), and down a column for the contravariant 𝒞(−, x).
  5. Multiplication. In a monoid M viewed as a one-object category, the only hom-set is the set of elements of M, and the hom functor sends an element m to the function h ↦ m · h. So the hom functor M → Set is M acting on itself by left multiplication — the action of example (vii) with S = M.
  6. Underlying sets. A group homomorphism ℤ → G is completely determined by where it sends 1, and 1 may be sent anywhere. So Grp(ℤ, G) is a copy of the underlying set of G: the forgetful functor of example (ii) is the hom functor Grp(ℤ, −), wearing a costume. Likewise Mon(ℕ, −) and Vect(ℝ, −).

Items 1, 2, 3 and 6 all say that some familiar functor is a hom functor in disguise. Making “in disguise” precise needs the natural isomorphisms of Lesson 3; functors that arise this way are called representable, and Lesson 9 is devoted to them. There the hom functors become the main characters of the whole subject: the Yoneda lemma says that an object A is completely captured by its hom functor.

§6 — Full, faithful, and essentially surjective

How much of the arrows a functor sees

A function between sets can be injective, surjective, both or neither. For functors the corresponding questions are asked one hom-set at a time. A functor F : 𝒞 → 𝒟 gives, for each pair of objects X, Y of 𝒞, a function between hom-sets:

𝒞(X, Y) → 𝒟(F X, F Y),     f ↦ F f.

Definition · Faithful, full, essentially surjective

A functor F : 𝒞 → 𝒟 is

  • faithful if each of these functions is injective: for parallel arrows, F f = F g forces f = g;
  • full if each is surjective: every arrow F X → F Y of 𝒟 is F f for some f : X → Y;
  • fully faithful if it is both;
  • essentially surjective if every object of 𝒟 is isomorphic to F X for some object X of 𝒞.

Read the definitions carefully. Faithful does not mean injective on arrows overall: it compares only arrows with the same source and target. The functor from the two-object discrete category to 𝟙 is faithful — every hom-set involved has at most one element — although it sends two different identity arrows to the same place. And essentially surjective asks for every object of 𝒟 to be reached only up to isomorphism, in keeping with Lesson 1’s principle that isomorphic objects are interchangeable.

The inclusion Ab → Grp is full and faithful but not essentially surjective: a non-abelian group is not isomorphic to any abelian one. A functor with all three properties loses nothing that category theory can see — Lesson 4 calls it an equivalence and makes it the right notion of two categories being “the same.”

What these properties buy

§3 showed that every functor preserves isomorphisms. The converse direction — reflecting them — is exactly what full faithfulness provides.

Theorem · Fully faithful functors reflect isomorphisms

Let F be fully faithful. If F f is an isomorphism, then so is f. Consequently, if F X ≅ F Y then X ≅ Y.

Proof. Let f : X → Y, and let k : F Y → F X be the inverse of F f. Because F is full, k = F g for some g : Y → X. Then F(g ∘ f) = F g ∘ F f = idF X = F(idX), and because F is faithful, g ∘ f = idX. In the same way f ∘ g = idY. So g is an inverse of f. For the second statement, any isomorphism u : F X → F Y is F f for some f by fullness, and that f is an isomorphism by the first part. ∎

Faithfulness alone already reflects the cancellation properties of Lesson 1.

Proposition · Faithful functors reflect monos and epis

Let F be faithful. If F f is monic then f is monic, and if F f is epic then f is epic.

Proof. Suppose F f is monic and f ∘ h = f ∘ k. Applying F gives F f ∘ F h = F f ∘ F k; cancel F f to get F h = F k; and F is faithful, so h = k. The epic case is the mirror image. ∎

Since the forgetful functors to Set are faithful, this explains a fact you may have used for years: in Grp, Mon, Vect or Top, an arrow whose underlying function is injective is monic, and one whose underlying function is surjective is epic.

Careful · Functors need not preserve monos or epis

The other direction fails. Lesson 1 showed that the inclusion ℕ → ℤ is an epimorphism in Mon. The forgetful functor Mon → Set sends it to a function that is not surjective — not an epimorphism of Set. The reason is instructive. A functor preserves any property expressed by an equation between composites, which is why isomorphisms, sections and retractions all survive (Exercise 2). But “monic” and “epic” are not equations: they are statements about all the arrows of a category, and a functor moves you to a category with different arrows.

§7 — Functors by hand

A functor between finite categories is two small tables

When both categories are finite, a functor is a finite object: one table saying where each object goes, another saying where each arrow goes. The laws are then finitely many equations. Three worked examples cover every situation you will meet in the exercises.

One object: check a homomorphism

Take the monoid (ℤ/3, +) of Lesson 1 as a one-object category, and try “multiply by 2” as a functor from it to itself. The object must go to the object; the arrow table is

arrow n012
F(n) = 2n mod 3021

Identities: the identity arrow is 0, and F(0) = 0. Composition: there are nine composable pairs, and each needs F(a + b) = F(a) + F(b). For instance F(1 + 2) = F(0) = 0 and F(1) + F(2) = 2 + 1 = 0; or F(2 + 2) = F(1) = 2 and F(2) + F(2) = 1 + 1 = 2. All nine hold for one reason: 2(a + b) = 2a + 2b. So doubling is a functor — in the language of §4(iv), a monoid homomorphism. Compare the map n ↦ n + 1: it sends the identity 0 to 1, so it fails at the first step (Exercise 10).

Thin categories: count the monotone maps

How many functors are there from 𝟚 to the chain 𝟛 of Lesson 1? By §4(iv) a functor between preorders is just a monotone map: once the objects are placed, each arrow has only one place to go, and every equation holds automatically because the target is thin. So we need the pairs (F0, F1) with F0 ≤ F1 in {0, 1, 2}:

(0,0),   (0,1),   (0,2),   (1,1),   (1,2),   (2,2).

Six functors. And 𝟛 has exactly six arrows — the functor (i, j) is the one that selects the arrow i → j, just as example (v) promised. The three functors (0,0), (1,1), (2,2) select identity arrows: they collapse 𝟚 onto a single object.

Groups: solve an equation

How many functors are there from ℤ/2 to ℤ/3, both viewed as one-object categories? A functor is a homomorphism φ, and it is determined by the single value x = φ(1). The law for the composite 1 + 1 = 0 demands x + x = φ(0) = 0 in ℤ/3, and the only solution is x = 0. So there is exactly one functor, the one sending everything to the identity.

From ℤ/3 to itself the constraint on x = φ(1) is x + x + x = 0, which every element of ℤ/3 satisfies. So there are three functors, n ↦ xn for x = 0, 1, 2: the constant functor, the identity functor, and the doubling functor of the first example.

The recipe in all three cases is the same: place the objects; give every arrow an image with the right source and target; check that identities go to identities; check the composable pairs. When the target is thin the last two steps cost nothing.

Optional · PythonFunctors, checked by machine

First, List as a functor on types. We lift ordinary functions with fmap and watch the two laws hold on real data.

list_functor.py — map is a functor
def fmap(f, xs):
    "lift an ordinary function to act on a list, elementwise"
    return [f(x) for x in xs]

inc = lambda x: x + 1
sq  = lambda x: x * x
data = [1, 2, 3, 4]

# Functor law 1:  fmap(id) == id
assert fmap(lambda x: x, data) == data

# Functor law 2:  fmap(g . f) == fmap(g) . fmap(f)
assert fmap(lambda x: sq(inc(x)), data) == fmap(sq, fmap(inc, data))

print(fmap(inc, data))            # [2, 3, 4, 5]
output[2, 3, 4, 5]

Now the finite-category version. A functor between finite categories is just two dictionaries — where each object goes, where each arrow goes — plus a promise that typing, identities, and composites are respected. A single check() verifies all three (it reuses Lesson 1’s FiniteCategory, repeated in the setup block so that this page runs on its own). We point it at “multiply by 2” on the one-object category (ℤ/3, +) — which, because that category is a monoid, is asking whether doubling is a monoid homomorphism.

setup.py — Lesson 1’s category checker, carried over
from itertools import product

class FiniteCategory:
    """objects, arrows (name -> (dom, cod)), a composition table,
       and a chosen identity arrow for each object."""
    def __init__(self, objects, arrows, comp, ident):
        self.obj, self.ar = set(objects), arrows
        self.comp, self.id = comp, ident

    def dom(self, a): return self.ar[a][0]
    def cod(self, a): return self.ar[a][1]
    def composable(self, g, f): return self.dom(g) == self.cod(f)

    def check(self):
        # 1. each identity is typed X -> X
        for X in self.obj:
            assert self.ar[self.id[X]] == (X, X)
        # 2. every composable pair has a composite, correctly typed
        for g, f in product(self.ar, repeat=2):
            if self.composable(g, f):
                gf = self.comp[(g, f)]
                assert self.ar[gf] == (self.dom(f), self.cod(g))
        # 3. identity law on both sides
        for f in self.ar:
            X, Y = self.ar[f]
            assert self.comp[(self.id[Y], f)] == f
            assert self.comp[(f, self.id[X])] == f
        # 4. associativity
        for h, g, f in product(self.ar, repeat=3):
            if self.composable(h, g) and self.composable(g, f):
                assert self.comp[(h, self.comp[(g, f)])] == \
                       self.comp[(self.comp[(h, g)], f)]
        return True
functor.py — a functor between finite categories
class Functor:
    """F : C -> D, given by a map on objects and a map on arrows."""
    def __init__(self, C, D, on_obj, on_arr):
        self.C, self.D, self.on_obj, self.on_arr = C, D, on_obj, on_arr

    def check(self):
        C, D, Fo, Fa = self.C, self.D, self.on_obj, self.on_arr
        for f in C.ar:                          # typing: F(f): F(dom) -> F(cod)
            X, Y = C.ar[f]
            assert D.ar[Fa[f]] == (Fo[X], Fo[Y])
        for X in C.obj:                         # preserves identities
            assert Fa[C.id[X]] == D.id[Fo[X]]
        for g, f in product(C.ar, repeat=2):    # preserves composition
            if C.composable(g, f):
                assert Fa[C.comp[(g, f)]] == D.comp[(Fa[g], Fa[f])]
        return True

# (Z/3, +) as a one-object category, carried over from Lesson 1
ar   = {n: ('*', '*') for n in range(3)}
comp = {(a, b): (a + b) % 3 for a in range(3) for b in range(3)}
Z3 = FiniteCategory({'*'}, ar, comp, {'*': 0})

# "multiply by 2" is a monoid homomorphism -- i.e. a functor of one-object cats
double = Functor(Z3, Z3, on_obj={'*': '*'},
                 on_arr={n: (2 * n) % 3 for n in range(3)})
print(double.check())
outputTrue

Going deeper

Contravariance, formalized at last

§2’s aside mentioned functors that reverse arrows. With Lesson 1’s Exercise 7 in hand there is nothing new to define: a contravariant functor from 𝒞 to 𝒟 is simply an ordinary (covariant) functor 𝒞op → 𝒟. Reversal is not a new species of functor; it is the old species, fed the opposite category. The composition law comes out flipped — F(g ∘ f) = F(f) ∘ F(g) — because composition in 𝒞op is itself flipped.

The flagship example is a matched pair on Set. The covariant powerset functor P sends a set to its set of subsets and a function f to the direct image S ↦ f(S). The contravariant powerset functor sends f the other way, to the inverse image T ↦ f−1(T) — and the identity (g ∘ f)−1 = f−1 ∘ g−1, socks-and-shoes from Lesson 1’s Exercise 8, is exactly the flipped composition law. Contravariant Set-valued functors have a name of their own — presheaves — and Lesson 9 is largely about one family of them: the hom functors of §5.

§8 — Exercises

Nineteen problems on functors

As before, the arrows-only proofs are the heart of the set — real conclusions drawn entirely from preservation of composition and identities. Every problem can be done by hand; Exercises 9, 10 and 12 also carry an optional Python version that reuses the FiniteCategory and Functor classes from the lab in §7.

Exercise 1warm-up

Let dbl be the doubling function x ↦ 2x. Apply the list functor to it: compute map(dbl) of the list [1, 2, 3].

Then state, precisely, the two laws that any well-behaved map function must satisfy, and say which functor law each corresponds to.

Show solution

map(dbl) sends [1, 2, 3] to [2, 4, 6] — apply the function to each element, keep the structure. (In the notation of the optional lab this is fmap(dbl, [1, 2, 3]).)

The laws: map(id) == id (mapping the do-nothing function over a list changes nothing) and map(g ∘ f) == map(g) ∘ map(f) (mapping a composite in one pass equals mapping the pieces in two passes). These are precisely the functor laws — identity-preservation and composition-preservation — with List in the role of F. The second law is what licenses a compiler to fuse two traversals into one.

Exercise 2arrows-only

An arrow r is a left inverse (a retraction) of f : X → Y if r ∘ f = idX.

Show that any functor F sends a left inverse to a left inverse: if r ∘ f = idX, then F r ∘ F f = idF X. Where exactly does each functor law get used?

Show solution

Apply F to both sides of the equation r ∘ f = idX. On the left, composition-preservation gives F(r ∘ f) = F r ∘ F f. On the right, identity-preservation gives F(idX) = idF X. Equal arrows have equal images, so F r ∘ F f = idF X.

Each law is used exactly once, on its own side of the equation. Run the same argument on a right inverse and combine the two, and you have re-derived the §3 theorem that functors preserve isomorphisms — this exercise is its load-bearing half.

Exercise 3structure

Lesson 1 established that a one-object category is the same thing as a monoid. Now take two monoids M and N, viewed as one-object categories, and consider a functor F between them.

Spell out the full dictionary: what data does F carry, and what do “preserves composition” and “preserves identities” become, stated in the language of monoids?

Show solution

The object map is trivial — one object must go to one object — so the only genuine data is the arrow map, a function φ from the elements of M to the elements of N.

Preserves composition becomes φ(a · b) = φ(a) · φ(b): the function respects the monoid operation. Preserves identities becomes φ(eM) = eN: the unit goes to the unit. Those two conditions are, word for word, the definition of a monoid homomorphism. So functors between one-object categories and monoid homomorphisms are the same notion — the concept “functor” specializes correctly.

Exercise 4examples

Consider the forgetful functor U : Grp → Set, which strips a group down to its underlying set and a homomorphism down to its underlying function. Two questions:

  1. If U f = U g for two homomorphisms f, g between the same groups, must f = g?
  2. Is every function between the underlying sets of two groups of the form U h for some homomorphism h?

The two properties you are probing have names — faithful and full. Which does U have?

Show solution

(a) Yes. A homomorphism is completely determined by what it does to elements — its underlying function. Two homomorphisms with the same underlying function are the same homomorphism. So U is injective on each hom-set: it is faithful.

(b) No. A typical function between two groups’ underlying sets does not respect multiplication — e.g. any function sending the identity element somewhere other than the identity. Such functions are not U of anything, so U is not full.

“Faithful but not full” is the characteristic signature of forgetful functors: forgetting structure loses no arrows, but the target category has many arrows that never came from the source.

Exercise 5think

Nothing in the definition of a functor requires the object map to be injective or surjective. Make that vivid: exhibit one functor that is wildly non-injective on objects, and one that is badly non-surjective. Small categories from Lesson 1 (𝟙, 𝟚) are enough raw material.

Show solution

Non-injective: the unique functor 𝒞 → 𝟙 from any category with at least two objects. Every object is crushed onto the single object of 𝟙 and every arrow onto its identity — the laws hold trivially, and injectivity fails as badly as possible.

Non-surjective: an inclusion 𝟙 → 𝒞 that picks out one object of a large category 𝒞, missing every other object.

The first functor collapses; the second merely samples. Functors are free to do either — they promise coherence, not faithfulness to size or shape.

Exercise 6counting

Let Z3 denote the one-object category built from the monoid ({0, 1, 2}, + mod 3), as in §7.

  1. How many functors are there 𝟙 → Z3?
  2. How many functors are there 𝟚 → Z3?
  3. What does the answer to (b) generalize to, for functors 𝟚 → 𝒞 into an arbitrary category?
Show solution

(a) Exactly 1. The object of 𝟙 must go to ∗, and its identity arrow must go to the identity 0. Nothing is free.

(b) Exactly 3. Both identities of 𝟚 are forced to 0, but the arrow u : 0 → 1 may be sent to any of the three arrows 0, 1, 2 — and each choice automatically satisfies both functor laws, since there are no non-trivial composites in 𝟚 to constrain it.

(c) In general, functors 𝟚 → 𝒞 correspond exactly to arrows of 𝒞. That is the precise meaning of the slogan “𝟚 selects an arrow” — small categories are probes, and this one probes for arrows.

Exercise 7arrows-only

§4(i) asserted that functors compose. Prove it in full: given functors F : 𝒞 → 𝒟 and G : 𝒟 → ℰ, define G ∘ F by X ↦ G(F X) on objects and f ↦ G(F f) on arrows, and verify both functor laws. Note carefully which law of which functor you invoke at each step.

Show solution

Identities. (G ∘ F)(idX) = G(F(idX)) = G(idF X) = idG F X. The middle equality is F’s identity law; the last is G’s, applied at the object F X.

Composition. (G ∘ F)(g ∘ f) = G(F(g ∘ f)) = G(F g ∘ F f) = G(F g) ∘ G(F f). First F’s composition law, then G’s, applied to the arrows F g and F f.

Typing checks out at every stage, so G ∘ F is a functor. Together with the identity functors this is exactly what makes Cat a category — the claim §4 made and this exercise cashes in.

Exercise 8structure

Fix an object D of a category 𝒟. The constant functor ΔD : 𝒞 → 𝒟 sends every object of 𝒞 to D and every arrow of 𝒞 to idD.

Verify the two functor laws for ΔD. Then describe, in a sentence, what ΔD does to any commuting diagram in 𝒞.

Show solution

Identities: ΔD(idX) = idD = idΔDX — true by construction. Composition: ΔD(g ∘ f) = idD, while ΔD(g) ∘ ΔD(f) = idD ∘ idD = idD. Equal.

ΔD crushes any diagram — however elaborate — down to the single object D decorated with identity loops. It is the maximally forgetful functor: it remembers only that a diagram existed. Constant functors look like throwaways, but they are the yardstick against which limits and colimits are defined in Lesson 7 — a cone over a diagram will be exactly a natural transformation out of a ΔD.

By hand. Objects: 0 ↦ ∗ and 1 ↦ ∗. Arrows: i0 ↦ 0 and i1 ↦ 0, because identities must go to the identity of the target, which is the element 0; and u ↦ 2. Exercise 10by hand · optional python

Not every map of arrows is a functor. Consider n ↦ (n + 1) mod 3 on the arrows of Z3, with the object fixed, proposed as a functor from Z3 to itself.

Exercise 11structure

Verify the claims of the Going-deeper section:

  1. Show the direct-image assignment P(f)(S) = { f(x) : x ∈ S } satisfies both (covariant) functor laws.
  2. Show the inverse-image assignment f ↦ f−1 satisfies the identity law and the flipped composition law, and say precisely which Lesson 1 exercise the flip is.
Show solution

(a) Identity: the direct image of S under id is S itself. Composition: (g ∘ f)(S) = { g(f(x)) : x ∈ S } = g(f(S)) — take the image in two stages or one, same set. Both laws hold, so P is a functor Set → Set.

(b) Identity: id−1(T) = T. Composition: x ∈ (g ∘ f)−1(T) means g(f(x)) ∈ T, i.e. f(x) ∈ g−1(T), i.e. x ∈ f−1(g−1(T)) — so (g ∘ f)−1 = f−1 ∘ g−1, order reversed. That reversal is Lesson 1, Exercise 8(c) — the socks-and-shoes law for inverses — resurfacing as the composition law of a functor out of Setop. One phenomenon, two bookkeepings.

The covariant powerset functor of the Going-deeper section sends a function to its direct-image map. Let k(x) = x + 1 and h(x) = x mod 2.

from itertools import combinations

def pmap(f, S):                       # direct image on subsets
    return {f(x) for x in S}

    S = list(S)
    return [set(c) for r in range(len(S)+1) for c in combinations(S, r)]

h2 = lambda x: x + 1

Exercise 13examples

Actions as functors (§4, example vii).

  1. A functor F : (ℕ, +) → Set is a set S with one function t = F(1) : S → S. Take S = {1, 2, 3, 4} and let t send 1 ↦ 2, 2 ↦ 3, 3 ↦ 1, 4 ↦ 4. Compute the function F(5).
  2. Describe, in the same spirit, what a functor from the group ℤ/2 to Set amounts to.
  3. How many functors ℤ/2 → Set send the object to the set {1, 2, 3}?
Show solution

(a) F(5) = t ∘ t ∘ t ∘ t ∘ t. On the cycle 1 → 2 → 3 → 1, three ticks return each point to itself, so five ticks act like two: 1 ↦ 3, 2 ↦ 1, 3 ↦ 2. And 4 stays put. So F(5) sends 1 ↦ 3, 2 ↦ 1, 3 ↦ 2, 4 ↦ 4.

(b) The group ℤ/2 has one non-identity arrow a, with a ∘ a = id. A functor must send it to a function s : S → S with s ∘ s = idS. So a functor ℤ/2 → Set is a set equipped with an involution — a symmetry that undoes itself, like a reflection.

(c) We need the functions s on {1, 2, 3} with s ∘ s = id: the identity, and the three swaps exchanging two points and fixing the third. Four functors. (The two 3-cycles are excluded: applying one twice gives the other, not the identity.)

Exercise 14by hand

Hom functors in the divisibility order on {1, 2, 3, 6} (§5).

  1. List the value of 𝒞(2, x) for each object x: a one-element set or the empty set.
  2. The arrow 2 → 6 must be sent by 𝒞(2, −) to a function 𝒞(2, 2) → 𝒞(2, 6), and the arrow 3 → 6 to a function 𝒞(2, 3) → 𝒞(2, 6). Say what each of these functions is.
  3. Now the contravariant functor 𝒞(−, 2): to which function does it send the arrow 1 → 2?
Show solution

(a) 𝒞(2, x) is non-empty exactly when 2 divides x: it is a one-element set for x = 2 and x = 6, and empty for x = 1 and x = 3.

(b) 𝒞(2, 2) → 𝒞(2, 6) is a function between one-element sets, and there is only one: it sends the arrow 2 → 2 to the composite 2 → 2 → 6, which is the arrow 2 → 6. And 𝒞(2, 3) → 𝒞(2, 6) is a function from the empty set to a one-element set: the empty function. Nothing needs to be sent anywhere.

(c) It runs backwards: from 𝒞(2, 2) to 𝒞(1, 2), by composing on the right with 1 → 2. Both are one-element sets, and the function sends 2 → 2 to the composite 1 → 2 → 2, the arrow 1 → 2.

In a thin category the hom functors carry no more information than the order itself — which is the point: they are the order, repackaged as functors. Lesson 9 shows that in every category the hom functors repackage the whole category.

Exercise 15arrows-only

Let F : 𝒞 → 𝒟 and G : 𝒟 → ℰ be functors.

  1. Show that if F and G are faithful then so is G ∘ F, and likewise for full.
  2. Show that if G ∘ F is faithful then F is faithful.
  3. Give an example where G ∘ F is faithful but G is not.
Show solution

(a) On each hom-set the functor G ∘ F acts as a composite of two functions,

𝒞(X, Y) → 𝒟(F X, F Y) → ℰ(G F X, G F Y).

A composite of injective functions is injective, and a composite of surjective functions is surjective.

(b) If F f = F g for parallel arrows f, g, then G F f = G F g, so f = g by faithfulness of the composite. (This is Lesson 1, Exercise 17(b) one level up: if a composite is injective, its first factor is.)

(c) Let F : 𝟙 → Mon pick out the monoid (ℕ, +), and let G : Mon → 𝟙 be the only functor there is. Then G ∘ F is the identity functor of 𝟙, certainly faithful. But G is not faithful: it sends every one of the many homomorphisms ℕ → ℕ to the same identity arrow.

Exercise 16think

Classify each functor: faithful? full? essentially surjective?

  1. The inclusion of (ℕ, ≤) into (ℤ, ≤).
  2. Reduction modulo 3, as a homomorphism (ℤ, +) → (ℤ/3, +) of one-object categories.
  3. The forgetful functor Pos → Set.
  4. The functor Set → Rel of Lesson 1 that keeps every set and sends a function to its graph.
Show solution

(a) Faithful and full, not essentially surjective. Between posets every functor is faithful. Full: if m ≤ n holds in ℤ for two natural numbers, it holds in ℕ. But −1 is not isomorphic to any natural number — in a poset, isomorphic means equal.

(b) Full and essentially surjective, not faithful. With one object on each side, essential surjectivity is automatic. Every element of ℤ/3 is the residue of some integer, so the single hom-set map is surjective: full. It is not injective — 0 and 3 both go to 0 — so the functor is not faithful.

(c) Faithful and essentially surjective, not full. A monotone map is determined by its underlying function. Every set is the underlying set of a poset: give it the order in which x ≤ y only when x = y. But not every function between posets is monotone.

(d) Faithful and essentially surjective, not full. A function is determined by its graph. Every set is hit exactly. But most relations are not graphs of functions (Lesson 1, Exercise 14).

Notice that no two of the three properties come as a package: each example has a different pair.

Exercise 17counting

Count the functors, using the methods of §7.

  2. From 𝟛 to 𝟚.

Exercise 18structure

The diagonal functor Δ : 𝒞 → 𝒞 × 𝒞 of §4(viii) sends X to (X, X) and f to (f, f).

  1. Verify the two functor laws.
  2. Show that Δ is faithful.
  3. Show that Δ is full exactly when 𝒞 is thin, and illustrate the failure in Set.
Show solution

(a) Identities and composites in the product category are formed slot by slot (Lesson 1, Exercise 12). So Δ(idX) = (idX, idX), which is the identity of (X, X); and Δ(g ∘ f) = (g ∘ f, g ∘ f) = (g, g) ∘ (f, f) = Δ g ∘ Δ f.

(b) If Δ f = Δ g then (f, f) = (g, g), so f = g.

(c) An arrow Δ X → Δ Y in 𝒞 × 𝒞 is any pair (f, g) of arrows X → Y, while the arrows in the image of Δ are the pairs with f = g. So Δ is full exactly when any two parallel arrows of 𝒞 are equal — when 𝒞 is thin. In Set, take X = Y = {0, 1}: the pair consisting of the identity and the function swapping 0 and 1 is an arrow Δ X → Δ X that is not Δ of anything.

Lesson 8 shows that the arrows Δ X → (A, B) — pairs of arrows out of X — are exactly what the product A × B is designed to classify.

Exercise 19arrows-only

Functors preserve what equations express, and nothing more.

  1. Recall from Lesson 1 that s is a split monomorphism if r ∘ s = id for some r. Show that every functor sends split monomorphisms to split monomorphisms, and split epimorphisms to split epimorphisms.
  2. Explain why the same argument cannot show that functors preserve monomorphisms, and name a functor and an arrow from §6 for which the corresponding statement about epimorphisms fails.
Show solution

(a) Apply F to the equation r ∘ s = idX: by Exercise 2, F r ∘ F s = idF X. So F s has the retraction F r, and F r has the section F s.

(b) “m is monic” is not an equation. It is an implication — for all h, k, if m ∘ h = m ∘ k then h = k — ranging over every pair of arrows into the source of m. Applying F tells us something about arrows of the form F h and F k only, while F m must be tested against all arrows of the target category, most of which need not come from the source. The warning in §6 gives a failure for the mirror-image property: the forgetful functor Mon → Set sends the epimorphism ℕ → ℤ to a function that is not surjective.

Recap

What to carry forward

  1. A functor maps objects to objects and arrows to arrows, preserving identities and composition — the two pieces of structure a category has.
  2. Functors send commuting diagrams to commuting diagrams and isomorphisms to isomorphisms; they may forget distinctions but never manufacture them.
  3. That iso-preservation is the licence behind algebraic invariants: differ after F, and you differed before.
  4. Identity functors plus functor composition make categories into a category, Cat — the subject becomes self-referential.
  5. Monoid homomorphisms and monotone maps are functors in disguise; so are monoid actions, and a lawful map in code.
  6. Every object A carries two hom functors, 𝒞(A, −) and 𝒞(−, A), whose functor laws are the category laws themselves.
  7. Faithful, full and essentially surjective measure how much a functor sees. Fully faithful functors reflect isomorphisms; no functor is obliged to preserve monos or epis.
