§1 — The payoff

Defining things by the company they keep

So far we have described objects from the outside — by their arrows — but we have not yet defined anything that way. This lesson makes the move — Lesson 5 gave a first glimpse of it, when the identity arrow of a slice category turned out to receive exactly one arrow from every object. A universal property characterizes an object as the best possible solution to a mapping problem: the object such that every other candidate factors through it, in exactly one way.

The template has two clauses, and both matter. Existence: for every candidate, some arrow does the job. Uniqueness: only one arrow does. Existence alone would give a “good enough” object; uniqueness is what makes it the object, canonical, with no arbitrary choices hiding inside. In the diagram above, the dashed amber arrow is this lesson’s signature mark: there exists exactly one arrow making the picture commute.

The reward for this austerity is the theorem we prove in §2: anything defined by a universal property is unique up to unique isomorphism. Two constructions built in wildly different ways — cartesian pairs versus some exotic encoding — are interchangeable the moment they satisfy the same universal property. Interfaces over implementations, stated as mathematics.

§2 — Terminal & initial objects

The simplest universal properties there are

Definition · Terminal and initial
  • An object T is terminal if for every object X there is exactly one arrow X → T. It is written 1, and the unique arrow !X : X → 1.
  • An object I is initial if for every object X there is exactly one arrow I → X. It is written 0.

In Set, a one-element set {∗} is terminal: a function into it has no choices to make, so there is exactly one from each X. The empty set is initial: the empty function is the unique map ∅ → X — there is nothing to send, hence nothing to choose, hence exactly one way to do it. (Vacuous, and correct.) Note the asymmetry: Set has many terminal objects — every singleton — which is exactly why the uniqueness theorem below matters. In a preorder, terminal means greatest element and initial means least; in Grp, the trivial group is both at once (a zero object).

The two ends of some familiar categories

A terminal object and an initial object are the two “ends” of a category — where every arrow can finish, and where every arrow can start. Whether a category has them, and what they are, is one of the first things worth knowing about it.

Two rows deserve a word. In Ring a homomorphism must send 1 to 1, so a homomorphism out of ℤ has no freedom at all — n must go to 1 + ⋯ + 1 — and there is exactly one into every ring: ℤ is initial. And a group with more than one element, viewed as a one-object category, has no terminal or initial object: its only object has several arrows to itself, not exactly one. Existence is never guaranteed. But when an end exists, the theorem below says it is essentially unique.

Theorem · Unique up to unique isomorphism

If T and T′ are both terminal in 𝒞, there is exactly one arrow T → T′, and it is an isomorphism.

Proof (arrows only). Terminality of T′ gives a unique arrow u : T → T′; terminality of T gives a unique v : T′ → T. Now consider v ∘ u : T → T. Since T is terminal, there is exactly one arrow T → T — and idT is such an arrow. So v ∘ u = idT, and symmetrically u ∘ v = idT′. Hence u is an isomorphism, and it was unique from the start. ∎

Read the proof again — it is four sentences, and the engine of all four is the word exactly. This one argument, lightly costumed, will re-prove itself for products below, for limits in Lesson 7, and for adjoints after that. It is the most reusable proof in the subject.

§3 — Products

The pair, without ever saying “pair”

What is the cartesian product A × B, arrows-only? Its interface: it comes with two projections, and knowing a map into A × B is exactly the same as knowing a map into A and a map into B. Promote the interface to the definition:

Definition · Product

A product of A and B is an object A × B together with arrows π1 : A × B → A and π2 : A × B → B (the projections) such that: for every object X and every pair of arrows f : X → A, g : X → B, there is exactly one arrow ⟨f, g⟩ : X → A × B with

π1 ∘ ⟨f, g⟩ = f   and   π2 ∘ ⟨f, g⟩ = g.

That is the hero diagram at the top of the page: the solid arrows are the given data, and the dashed ⟨f, g⟩ is the one arrow the universal property conjures. In Set it is x ↦ (f(x), g(x)) — and the uniqueness clause holds because any map m with π1 ∘ m = f and π2 ∘ m = g has both coordinates of m(x) pinned down.

Now the definition goes traveling. In Grp, the same property picks out the direct product of groups. In a preorder, an arrow X → A just means X ≤ A, so the product of A and B is the greatest element below both — the meet. In the divisibility order on positive integers, “below” means “divides,” and the product of two numbers is their gcd. One definition; pairs, direct products, meets, and gcds fall out as instances. And by the same style of argument as §2’s theorem, any two products of A and B are uniquely isomorphic (Exercise 8) — so we may speak of the product.

A warning with content: products need not exist. The definition is a specification, not a guarantee, and some categories simply have no object meeting it — §6 exhibits two, and proves it by listing the candidates. Whether a category has products is real information about the category.

A product is a terminal object

The uniqueness of products need not be proved separately. It is §2’s theorem, applied in a category built with the kit of Lesson 5. Fix A and B, and consider the spans over them: triples (X, f, g) with f : X → A and g : X → B. Spans form a category, in which an arrow from (X, f, g) to (X′, f′, g′) is an arrow m : X → X′ compatible with both legs,

f′ ∘ m = f    and    g′ ∘ m = g.

(In the language of Lesson 5 it is the comma category of the diagonal functor over the pair (A, B).) Now read the definition of the product again: for every span (X, f, g) there is exactly one arrow to the span (A × B, π1, π2). A product of A and B is precisely a terminal object in the category of spans. So any two products are isomorphic by a unique isomorphism of spans — one compatible with the projections — and nothing new has to be proved. This manoeuvre, build the right category and look for its terminal object, is the pattern behind every universal property, and Lesson 7 uses it to define all limits at once.

Calculating with products

The universal property is also a practical calculus. Its uniqueness clause gives a test for equality of arrows into a product:

Proposition · Arrows into a product are determined by their components

If m, m′ : X → A × B satisfy π1 ∘ m = π1 ∘ m′ and π2 ∘ m = π2 ∘ m′, then m = m′.

Proof. Put f = π1 ∘ m and g = π2 ∘ m. Both m and m′ are arrows whose composites with the projections are f and g. There is exactly one such arrow, ⟨f, g⟩. ∎

Everything else follows from this test. For any h : W → X,

⟨f, g⟩ ∘ h = ⟨f ∘ h, g ∘ h⟩,

because both sides have the same two components: π1 ∘ ⟨f, g⟩ ∘ h = f ∘ h, and similarly for π2. And two arrows f : A → A′ and g : B → B′ combine into an arrow between products,

f × g = ⟨f ∘ π1, g ∘ π2⟩ : A × B → A′ × B′,

which in Set is (a, b) ↦ (f(a), g(b)). The same test shows (f′ × g′) ∘ (f × g) = (f′ ∘ f) × (g′ ∘ g) and id × id = id. So in a category where every pair of objects has a product, the product is a bifunctor 𝒞 × 𝒞 → 𝒞 in the sense of Lesson 5 — its action on arrows was forced by the universal property, with no further choices.

§4 — Coproducts & duality

Flip every arrow, get a second theory free

Lesson 1’s Exercise 4 built the opposite category 𝒞op: same objects, every arrow reversed. Here is why that construction earns its keep. Any arrows-only definition can be interpreted in 𝒞op instead of 𝒞, which reverses every arrow in the definition — producing a dual concept in 𝒞 itself. Initial is dual to terminal. And dual to the product is:

Definition · Coproduct (the product, arrows reversed)

A coproduct of A and B is an object A + B with arrows ι1 : A → A + B and ι2 : B → A + B (the injections) such that for every X and every f : A → X, g : B → X, there is exactly one [f, g] : A + B → X with [f, g] ∘ ι1 = f and [f, g] ∘ ι2 = g.

In Set, the coproduct is the disjoint union: to define a function out of A ⊔ B you say what happens on the A-part and what happens on the B-part, and [f, g] is exactly that case split — in code, pattern-matching on a tagged union or Either type. In a preorder it is the join (least upper bound); in divisibility, the lcm. In Grp it is the free product — famously not the direct product, a reminder that duals can look very different from their originals even when the definitions are mirror images.

The duality principle

Every theorem proved from the category axioms alone dualizes: reverse all arrows in both the statement and the proof, and the result is again a theorem, because the opposite of a category is again a category (Lesson 5, §2, where the principle was proved). So §2’s uniqueness theorem for terminal objects is automatically also a uniqueness theorem for initial objects, and the uniqueness of products yields uniqueness of coproducts — no new work. One proof, two theorems, forever. This is the single best bargain in mathematics.

§5 — A catalogue

The same two definitions, in eight categories

One definition of product and one of coproduct, read in different categories, produce a remarkable range of constructions. The table collects the ones met so far and adds a few more.

Three rows repay a closer look.

Vector spaces. The direct sum V ⊕ W consists of pairs (v, w). With the two projections it is the product, for the same reason as in Set. But it is also the coproduct, with injections v ↦ (v, 0) and w ↦ (0, w): given linear maps f : V → X and g : W → X, the unique linear map out of V ⊕ W restricting to them is

[f, g](v, w) = f(v) + g(w).

The formula uses addition in X — which is why it is available for vector spaces and abelian groups but not for sets or for groups in general. An object that is a product and a coproduct at once is called a biproduct.

Categories. The product category of Lesson 5 is the product in Cat: a functor into 𝒞 × 𝒟 is exactly a pair of functors, one into each factor. The construction of Lesson 1, Exercise 5 was a universal property in waiting.

Relations. In Rel the product of two sets is not their cartesian product but their disjoint union. A relation from W to the disjoint union X ⊔ Y is a set of pairs, each ending in X or in Y — so it is the same thing as a relation from W to X together with a relation from W to Y, which is the universal property of a product. Because Rel is its own opposite (Lesson 1, Exercise 19), the same object is also the coproduct. The moral: a universal property takes its meaning from the arrows of the category, and changing the arrows changes the answer, even when the objects are the same sets.

§6 — Universal properties by hand

“Exactly one” is something you can check

A universal property is a statement about all competitors, so in a small category it can be verified by listing them. Four computations, two successes and two instructive failures.

Products and coproducts in the diamond

Work in the divisibility order on {1, 2, 3, 6} pictured in §3. A product of 2 and 3 must first of all be a candidate: an object with arrows to both, that is, a common divisor. The only common divisor of 2 and 3 here is 1. Is it universal? Every object X with arrows to 2 and to 3 must have exactly one arrow to 1 — and the only such X is 1 itself, which has its identity. So 2 × 3 = 1, the greatest common divisor.

For 2 and 6 there are two candidates, 1 and 2 (both divide 2 and 6). The universal one is the candidate that every candidate maps to: 1 | 2, so 2 × 6 = 2. In an order, “universal among lower bounds” just means greatest lower bound. Dually the coproduct of 2 and 3 is the least of their common multiples, and the only common multiple available is 6.

A product that does not exist

Now take the four-element order with a ≤ x, a ≤ y, b ≤ x, b ≤ y and no other relations besides reflexivity: two lower elements, each below two upper ones.

The candidates for x × y are a and b. If a were the product, the candidate b would need an arrow to a; there is none. By symmetry b fails too. So x and y have no product, although they have lower bounds. The universal property asks for a single best candidate, and here the candidates do not agree on a best.

A category with no products at all

The one-object category of the monoid (ℤ/3, +) is not thin, so the uniqueness clause comes into play. A product of the only object ∗ with itself would be ∗ again, with two projections p and q — two elements of ℤ/3. For every pair of arrows (f, g) there would have to be exactly one mediating arrow m with

p + m = f    and    q + m = g.

The first equation forces m = f − p, the second m = g − q. These agree only when f − g = p − q. So for any choice of projections, the pairs (f, g) with f − g ≠ p − q — six of the nine — have no mediating arrow at all. No product exists. Existence fails, not uniqueness. A product must be able to hold two independent pieces of information, and a single object whose arrows form a group has no room for that (Exercise 15 gives the general statement).

The universal property, counted

In Set the two universal properties can be checked by counting functions. The product property says that functions X → A × B correspond exactly to pairs of functions X → A and X → B. Take sets with |X| = 2, |A| = 3, |B| = 2: there are (3 · 2)2 = 36 functions into the product, and 32 · 22 = 36 pairs. The coproduct property says that functions A + B → X correspond to pairs of functions A → X and B → X: there are 23 + 2 = 32 of the first and 23 · 22 = 32 of the second. In general

(a b)x = ax · bx    and    xa + b = xa · xb.

The laws of exponents from school are the universal properties of product and coproduct, counted.

Optional · PythonUniversal properties as search problems

In a finite category, “there exists exactly one arrow such that…” is checkable by enumeration. That makes every definition in this lesson executable. We write finders for terminal objects, initial objects, and products, and point them at the divisibility poset from §3. (These build on Lesson 1’s FiniteCategory class, repeated in the setup block.)

setup.py — Lesson 1’s category class, carried over
from itertools import product

class FiniteCategory:
    """objects, arrows (name -> (dom, cod)), a composition table,
       and a chosen identity arrow for each object."""
    def __init__(self, objects, arrows, comp, ident):
        self.obj, self.ar = set(objects), arrows
        self.comp, self.id = comp, ident

    def dom(self, a): return self.ar[a][0]
    def cod(self, a): return self.ar[a][1]
    def composable(self, g, f): return self.dom(g) == self.cod(f)

    def check(self):
        # 1. each identity is typed X -> X
        for X in self.obj:
            assert self.ar[self.id[X]] == (X, X)
        # 2. every composable pair has a composite, correctly typed
        for g, f in product(self.ar, repeat=2):
            if self.composable(g, f):
                gf = self.comp[(g, f)]
                assert self.ar[gf] == (self.dom(f), self.cod(g))
        # 3. identity law on both sides
        for f in self.ar:
            X, Y = self.ar[f]
            assert self.comp[(self.id[Y], f)] == f
            assert self.comp[(f, self.id[X])] == f
        # 4. associativity
        for h, g, f in product(self.ar, repeat=3):
            if self.composable(h, g) and self.composable(g, f):
                assert self.comp[(h, self.comp[(g, f)])] == \
                       self.comp[(self.comp[(h, g)], f)]
        return True
universal.py — finders for universal objects
def arrows_between(C, X, Y):
    return [a for a, (d, c) in C.ar.items() if d == X and c == Y]

def terminal_objects(C):
    "T is terminal iff every object has EXACTLY ONE arrow into T."
    return [T for T in C.obj
            if all(len(arrows_between(C, X, T)) == 1 for X in C.obj)]

def initial_objects(C):
    return [I for I in C.obj
            if all(len(arrows_between(C, I, X)) == 1 for X in C.obj)]

def is_product(C, P, pA, pB):
    "Check the universal property of (P, pA: P->A, pB: P->B)."
    A, B = C.cod(pA), C.cod(pB)
    for X in C.obj:
        for f in arrows_between(C, X, A):
            for g in arrows_between(C, X, B):
                mediators = [m for m in arrows_between(C, X, P)
                             if C.comp[(pA, m)] == f and C.comp[(pB, m)] == g]
                if len(mediators) != 1:      # exists AND is unique
                    return False
    return True

def find_products(C, A, B):
    return [(P, pA, pB) for P in C.obj
            for pA in arrows_between(C, P, A)
            for pB in arrows_between(C, P, B)
            if is_product(C, P, pA, pB)]

# The divisibility order on {1, 2, 3, 6}:  arrow a -> b  iff  a divides b
objs = {1, 2, 3, 6}
ar   = {f"{a}|{b}": (a, b) for a in objs for b in objs if b % a == 0}
comp = {}
for g, (gs, gt) in ar.items():
    for f, (fs, ft) in ar.items():
        if ft == gs:
            comp[(g, f)] = f"{fs}|{gt}"      # thin category: forced
ident = {n: f"{n}|{n}" for n in objs}
Div = FiniteCategory(objs, ar, comp, ident)

print("initial: ", initial_objects(Div))
print("terminal:", terminal_objects(Div))
print("2 x 3 =", find_products(Div, 2, 3))   # expect gcd = 1
print("2 x 6 =", find_products(Div, 2, 6))   # expect gcd = 2
outputinitial: [1] terminal: [6] 2 x 3 = [(1, '1|2', '1|3')] 2 x 6 = [(2, '2|2', '2|6')]

The finder confirms §3’s claims: in the divisibility order, initial is 1, terminal is 6, and products compute gcds. Now the promised non-existence result. In the one-object category Z3 (our running monoid), a product of ∗ with ∗ would need projections p, q such that every pair (f, g) factors uniquely — and no choice of p, q manages it. The search space is tiny, so exhaustion is a proof:

no_products.py — a category with no products
# Z3 = one object '*', arrows {0,1,2}, composition = addition mod 3
zar  = {n: ('*', '*') for n in range(3)}
zcmp = {(a, b): (a + b) % 3 for a in range(3) for b in range(3)}
Z3   = FiniteCategory({'*'}, zar, zcmp, {'*': 0})

print(find_products(Z3, '*', '*'))    # exhaustive search over all
                                      # candidate (P, p, q) triples
output[]

The reason is the hand computation above: a mediating arrow exists only when f − g = p − q, which fails for six of the nine pairs. Finally, the product in Set itself, with its mediating map as a working function:

pairing.py — the product in Set
def pairing(f, g):
    "the unique mediating map  <f, g> : X -> A x B"
    return lambda x: (f(x), g(x))

fst = lambda p: p[0]
snd = lambda p: p[1]

X = [0, 1, 2]
f = lambda x: x + 10          # f : X -> A
g = lambda x: x * x           # g : X -> B
m = pairing(f, g)

# both triangles of the universal property commute:
assert all(fst(m(x)) == f(x) for x in X)
assert all(snd(m(x)) == g(x) for x in X)
print([m(x) for x in X])
output[(10, 0), (11, 1), (12, 4)]
Going deeper

Elements, generalized

Terminal objects quietly repair the ban on elements. In Set, an arrow 1 → X from the one-point set is exactly a choice of one element of X — so “element” can be defined arrows-only: a global element of X is an arrow 1 → X from the terminal object. In Set this recovers everything: functions are determined by what they do to global elements.

In most categories, though, global elements are scarce, and arrows are not determined by them. In a poset only the top element has one; in Grp every group has exactly one, so global elements cannot tell any two parallel homomorphisms apart (Exercise 17). The repair is to widen the probe: an arrow U → X from an arbitrary object is a generalized element of X “of shape U.” Probing with all shapes at once recovers everything in every category — that is the course’s slogan, and Lesson 9’s Yoneda lemma is precisely the theorem that the full dossier of generalized elements determines the object. This little section is the bridge between the slogan’s two banks.

§7 — Exercises

Seventeen problems on universal properties

These lean on the uniqueness clause more than any previous set — whenever you are stuck, ask “what is the only arrow that could possibly work here?” and let exactly one do the rest. The problems are grouped by topic, following the lesson’s sections, and within each group they run from easier to harder. Exercise 16 has an optional Python part; everything else is pencil and paper.

Terminal and initial objects

§2 · Exercises 1–5

Exercise 1warm-up

Work in Set. For a set X with 5 elements:

  1. How many functions are there from X to the one-element set {∗}? What does your answer confirm?
  2. How many functions are there from the empty set ∅ to X? And how many from X to ∅? What do these two answers say about ∅?
Show solution

(a) Exactly one. A function must assign each of the 5 elements a value in {∗}, and there is only one value available — no choices anywhere. This confirms singletons are terminal.

(b) From ∅ to X: exactly one — the empty function. There is nothing to assign, hence exactly one way to complete the (empty) assignment. From X to ∅: zero — element x would need a value in ∅, and there are none. So ∅ is initial but not terminal: Set has no zero object, unlike Grp. The count “one map out, no maps in” is the entire personality of the empty set, expressed in arrows.

Exercise 2examples

A zero object is one that is initial and terminal at once. §2 noted that the trivial group is a zero object in Grp.

  1. Verify both halves: for any group G, count the homomorphisms {e} → G and G → {e}.
  2. Explain why the analogous count fails in Set, even though Set has both an initial and a terminal object.
Show solution

(a) A homomorphism must send identity to identity. Out of {e}: the only element must go to the identity of G, so exactly one homomorphism — {e} is initial. Into {e}: every element has nowhere to go but e, so again exactly one — terminal too. One object, both properties: a zero object.

(b) In Set the initial object is ∅ and the terminal objects are singletons, and no set is both: ∅ ≇ {∗} (there is no arrow {∗} → ∅ at all, per Exercise 1). The difference-maker is the group identity: it gives every hom-set a guaranteed inhabitant, collapsing “empty” and “one-point” into the same object. Whether a category has a zero object is a coarse but genuinely useful invariant — it is why “the zero map” makes sense between any two groups but not between any two sets.

Exercise 3examples

Initial objects, counted. The table in §2 says that ℤ is initial in Ring: from ℤ to any ring there is exactly one homomorphism (which must send 1 to 1).

  1. Describe the unique ring homomorphism ℤ → ℤ/6.
  2. How many ring homomorphisms are there from ℤ/2 to ℤ? What does the answer say about whether ℤ/2 is initial?
  3. Why is there exactly one ring homomorphism from any ring to the zero ring, and no homomorphism from the zero ring to ℤ?
Show solution

(a) It sends n to its residue modulo 6 — the image of n is forced to be 1 + ⋯ + 1, n times.

(b) None. A homomorphism φ would need φ(1) = 1, hence φ(1 + 1) = 2; but 1 + 1 = 0 in ℤ/2, so also φ(1 + 1) = φ(0) = 0. Since 2 ≠ 0 in ℤ, no such φ exists. An initial object has exactly one arrow to every object, so ℤ/2 is not initial.

(c) The zero ring has a single element, so there is exactly one function into it, and it preserves everything: terminal. A homomorphism out of it would send its one element, which is both 0 and 1, to both 0 and 1 of the target — possible only if the target also has 0 = 1. So the zero ring is terminal but not initial, and Ring, like Set, has no zero object.

Exercise 4arrows-only

State and prove the dual of §2’s theorem: any two initial objects are isomorphic via a unique isomorphism.

Write the proof out in full — then compare it, line by line, with the terminal-object proof, and mark where each arrow reversed.

Show solution

Let I and I′ be initial. Initiality of I gives a unique u : I → I′; initiality of I′ gives a unique v : I′ → I. The composite v ∘ u : I → I is an arrow out of the initial I, of which there is exactly one — and idI qualifies. So v ∘ u = idI, and symmetrically u ∘ v = idI′: a unique isomorphism.

Comparing: every “arrow into” became “arrow out of,” every use of terminality became initiality, and the composite v ∘ u was pinned down as an endomorphism of I rather than T. Nothing else changed. That mechanical translation is the duality principle in action — you could have skipped the proof entirely and cited §4’s amber box, but it is worth doing by hand exactly once.

Exercise 5think

Lesson 4 promised a one-line reason why Set is not equivalent to its opposite. Here it is, in three steps.

  1. Show that in Set, every arrow into the initial object is an isomorphism.
  2. Identify the initial object of Setop, and exhibit an arrow into it that is not an isomorphism.
  3. Conclude that Set and Setop are not equivalent. (You may use the standing fact of Lesson 4 that equivalences preserve everything defined by arrows, including initial objects and isomorphisms.)
Show solution

(a) The initial object is ∅. A function X → ∅ exists only when X = ∅, and then it is the identity of ∅.

(b) Initial in Setop means terminal in Set: a one-element set 1. An arrow X → 1 of Setop is a function 1 → X in Set — an element of X. Take X = {0, 1} and the element 0: this function is not a bijection, so it is not an isomorphism in Set, nor in Setop (the isomorphisms are the same).

(c) “Every arrow into the initial object is an isomorphism” is a statement about arrows only, so an equivalence would carry it from Set to Setop. It holds in one and fails in the other.

The two ends of Set are genuinely different: nothing maps into the empty set, but plenty maps out of the one-point set. Compare Grp or Vect, where the two ends coincide — a hint of why those categories are so much more symmetric.

Exercise 6structure

Work in an arbitrary preorder, viewed as a category.

  1. Unwind the definitions: what do “terminal object” and “initial object” mean in order language?
  2. Unwind the product: show that a product of a and b is exactly a meet (greatest lower bound), and note which part of the universal property becomes which clause of “greatest lower bound.”
Show solution

(a) Terminal: an object with an arrow from everything — i.e. an element ⊤ with x ≤ ⊤ for all x: a greatest element. Dually, initial is a least element. (Uniqueness of arrows is free — the category is thin.)

(b) The projections a × b → a and a × b → b say the product is a lower bound: a × b ≤ a and a × b ≤ b. The mediating-arrow clause says every x with x ≤ a and x ≤ b satisfies x ≤ a × b — the product is greatest among lower bounds. Existence of the mediator is the “greatest” clause; its uniqueness is free by thinness. So products in a preorder are meets, and dually coproducts are joins — and in the divisibility order these are gcd and lcm, as §6 verified.

Exercise 7arrows-only

Using only the test of §3 — arrows into a product are equal when their components are — prove:

  1. ⟨π1, π2⟩ = idA × B.
  2. For f : A → A′, g : B → B′ and arrows a : X → A, b : X → B: (f × g) ∘ ⟨a, b⟩ = ⟨f ∘ a, g ∘ b⟩.
Show solution

(a) Both sides are arrows A × B → A × B. The components of ⟨π1, π2⟩ are π1 and π2 by definition; the components of the identity are π1 ∘ id = π1 and π2 ∘ id = π2. Same components, same arrow.

(b) Recall f × g = ⟨f ∘ π1, g ∘ π2⟩. The first component of the left side is π1 ∘ (f × g) ∘ ⟨a, b⟩ = f ∘ π1 ∘ ⟨a, b⟩ = f ∘ a, which is the first component of the right side. The second components agree in the same way.

Every identity about pairing is proved like this: compose with each projection and compare. The uniqueness clause of the universal property turns into a method of calculation.

Exercise 8arrows-only

Adapt §2’s uniqueness proof to products. Suppose (P, π1, π2) and (P′, π′1, π′2) are both products of A and B. Show there is a unique isomorphism u : P → P′ that is compatible with the projections, i.e. π′1 ∘ u = π1 and π′2 ∘ u = π2.

Hint: to show a certain composite equals an identity, ask what the uniqueness clause says about arrows P → P that commute with both projections.

Show solution

The universal property of P′, applied to the arrows π1, π2 out of P, produces a unique u = ⟨π1, π2⟩′ : P → P′ compatible with the projections. Symmetrically, P’s universal property produces v : P′ → P with πi ∘ v = π′i.

Now the punchline. The composite v ∘ u : P → P commutes with both projections: πi ∘ (v ∘ u) = π′i ∘ u = πi. But P’s universal property, applied to the pair (π1, π2) itself, says there is exactly one arrow P → P commuting with both projections — and idP visibly does. Therefore v ∘ u = idP, and symmetrically u ∘ v = idP′. Same skeleton as §2: manufacture arrows with existence, collapse composites with uniqueness. Once you have written this proof twice you will never need to write it again — Lesson 7 states it once for all limits.

Exercise 9arrows-only

Let 1 be a terminal object. Show that for every object A, the object A itself, with the arrows idA : A → A and !A : A → 1, is a product of A and 1. Conclude that A × 1 ≅ A whenever the product exists.

Show solution

Let X be any object with arrows f : X → A and t : X → 1. We need exactly one m : X → A with idA ∘ m = f and !A ∘ m = t. The first equation forces m = f. And m = f satisfies the second automatically: !A ∘ f and t are both arrows X → 1, and there is only one. So (A, idA, !A) has the universal property of the product.

Since products are unique up to isomorphism (§3), any product A × 1 is isomorphic to A. In Set this is the bijection (a, ∗) ↦ a; in a preorder with a top element it is a ∧ ⊤ = a; counted, it is a · 1 = a. The terminal object is the unit for the product, which is why it is written 1.

Exercise 10arrows-only

Products associate, up to the usual unique isomorphism. Suppose the products (A × B) × C and A × (B × C) both exist.

Equip (A × B) × C with three “projections” to A, B, and C, and show it satisfies the universal property of a triple product: for any f : X → A, g : X → B, h : X → C, exactly one arrow into it commutes with all three. Conclude — without further computation — that (A × B) × C ≅ A × (B × C).

Show solution

The three projections: π1 ∘ π1, π2 ∘ π1, and π2 (outer). Given f, g, h, build the mediator in two stages: pair f and g into ⟨f, g⟩ : X → A × B, then pair with h: ⟨⟨f, g⟩, h⟩. The three triangles commute by unwinding the two pairings.

Uniqueness stacks the two uniqueness clauses: a competitor m commuting with all three projections has π1 ∘ m commuting with both inner projections, so π1 ∘ m = ⟨f, g⟩ by the inner product’s uniqueness — and then m = ⟨⟨f, g⟩, h⟩ by the outer’s. So (A × B) × C is a triple product; by the mirror argument so is A × (B × C); and §2’s theorem (two objects with the same universal property) supplies the unique isomorphism, no components ever computed. The same template gives commutativity A × B ≅ B × A and, in Lesson 7’s language, both are limits over the same three-dot diagram — associativity is then not even a theorem, just two names for one limit.

Coproducts

§4–§5 · Exercises 11–12

Exercise 11structure

In Set, take A = {1, 2} and B = {2, 3}, and let X = {'lo', 'hi'}. Define f : A → X by 1, 2 ↦ 'lo' and g : B → X by 2 ↦ 'lo', 3 ↦ 'hi'.

  1. Describe the coproduct A + B concretely. Why must the two copies of the element 2 be kept apart?
  2. Write out the copairing [f, g] : A + B → X explicitly, and check that both triangles commute.
Show solution

(a) The coproduct is the disjoint union — implement it with tags: A + B = {('L',1), ('L',2), ('R',2), ('R',3)}, with injections ι1(a) = ('L', a) and ι2(b) = ('R', b). The two 2’s must stay distinct because the universal property demands that f and g be recoverable independently: had we merged the 2’s, a pair with f(2) ≠ g(2) would have no well-defined copairing at all. (Here f(2) = g(2) = 'lo' by luck, but the coproduct must work for every pair.)

(b) [f, g] pattern-matches on the tag: ('L',1) ↦ 'lo', ('L',2) ↦ 'lo', ('R',2) ↦ 'lo', ('R',3) ↦ 'hi'. The triangles: [f,g](ι1(a)) = f(a) for both a, and [f,g](ι2(b)) = g(b) for both b — check each of the four elements. This is exactly the match statement on an Either/tagged-union type; the coproduct’s universal property is the mathematical spec of case analysis.

Exercise 12structure

Verify the claim of §5 that in Vect the direct sum V ⊕ W, with the injections i1(v) = (v, 0) and i2(w) = (0, w), is a coproduct. Given linear maps f : V → X and g : W → X:

  1. check that [f, g](v, w) = f(v) + g(w) is linear and satisfies [f, g] ∘ i1 = f and [f, g] ∘ i2 = g;
  2. show that it is the only linear map with those two properties.

Where does the argument break down in Set?

Show solution

(a) Linearity: [f, g] of a sum of pairs is f(v + v′) + g(w + w′) = (f(v) + g(w)) + (f(v′) + g(w′)), and similarly for scalar multiples. And [f, g](v, 0) = f(v) + g(0) = f(v), since a linear map sends 0 to 0; likewise [f, g](0, w) = g(w).

(b) Let h be linear with h ∘ i1 = f and h ∘ i2 = g. Every pair decomposes as (v, w) = (v, 0) + (0, w), so by linearity h(v, w) = h(v, 0) + h(0, w) = f(v) + g(w).

In Set there is no way to write a pair (v, w) as a combination of something from the image of i1 and something from the image of i2 — there is no 0 to pad with and no + to combine with. That is why the cartesian product of sets is not their coproduct, and why the two coincide exactly in categories whose arrows can be added.

Universal properties by hand

§6 · Exercises 13–16

Exercise 13counting

Check the two universal properties in Set by counting, as in §6. Let |A| = 2, |B| = 3 and |X| = 2.

  1. How many functions are there X → A × B, and how many pairs of functions (X → A, X → B)?
  2. How many functions A + B → X, and how many pairs (A → X, B → X)?
  3. The product property applied to the empty family says: there is exactly one arrow X → 1. Which law of exponents is that?
Show solution

(a) |A × B| = 6, so 62 = 36 functions; and 22 · 32 = 4 · 9 = 36 pairs.

(b) |A + B| = 5, so 25 = 32 functions; and 22 · 23 = 4 · 8 = 32 pairs.

(c) 1x = 1: there is exactly one function from a set with x elements to a one-element set. Dually, x0 = 1 counts the single function from the empty set — initiality of ∅. Each law of exponents is a universal property with the arrows counted.

Exercise 14by hand

Products that fail to exist, in two small orders.

  1. In the divisibility order on {2, 3, 6} — the diamond with its bottom removed — show that 2 and 3 have no product. Do they have a coproduct?
  2. In the order of §6 with a, b below x, y: do a and b have a coproduct? A product?
Show solution

(a) A product needs at least one candidate: an element dividing both 2 and 3. In {2, 3, 6} there is none, so there is no product. The coproduct exists: the only common multiple is 6, and it is trivially the least.

(b) The candidates for the coproduct of a and b are their common upper bounds, x and y. Neither is below the other, so there is no least one: no coproduct — the mirror image of the failure in §6. For the product, a candidate must be below both a and b; nothing is, so there is no product either.

Part (a) fails for lack of candidates, part (b) for lack of a best candidate. These are the only two ways a universal object can fail to exist.

Exercise 15think

§6 showed that the one-object category Z3 has no binary products. Now prove the general statement, for the one-object category built from a group (G, +) with more than one element.

Suppose (∗, p, q) were a product of ∗ with ∗. Analyze what a mediating arrow for a pair (f, g) would have to be, and derive a contradiction.

Show solution

A mediator for the pair (f, g) is an element m ∈ G with p + m = f and q + m = g. In a group each equation has exactly one solution: m = −p + f from the first and m = −q + g from the second. A mediator exists iff these agree, i.e. iff −p + f = −q + g, i.e. iff g = q − p + f.

But the universal property requires a mediator for every pair (f, g) ∈ G × G — and the condition pins g to a single value once f is chosen. Since |G| > 1, choose any g′ ≠ q − p + f: the pair (f, g′) has no mediator. Existence fails, so no (p, q) works, so there is no product. Intuition to keep: a product must be able to store two independent pieces of information, and a single object whose arrows form a group has no room — every equation is exactly solvable, leaving no slack for a second coordinate.

Exercise 16by hand · optional python

Dualize the product computations of §6.

  1. In the divisibility order on {1, 2, 3, 6}, find the coproduct of 2 and 3 directly from the definition: list the candidates, and check the universal property.
  2. Explain, using the duality principle and the fact that addition modulo 3 is commutative, why the one-object category Z3 has no coproducts either.
Optional · Python

Write find_coproducts(C, A, B) by dualizing find_products from the lab in §6 — reverse the direction of the candidate injections and of the mediating arrow, and flip the order of each composition accordingly.

Run it on the divisibility poset to confirm that the coproduct of 2 and 3 is 6 (the lcm). Then run it on Z3 and interpret the result in the light of duality.

Show solution

By hand. (a) A candidate is an object with arrows from both 2 and 3: a common multiple. The only one in the diamond is 6. It is universal: any X with 2 | X and 3 | X is 6 itself, and there is exactly one arrow 6 → 6. So 2 + 3 = 6, the least common multiple.

(b) A coproduct in a category is a product in its opposite. The opposite of a one-object category reverses the order of multiplication (Lesson 5, §2), and for a commutative monoid that changes nothing: Z3op = Z3. So a coproduct in Z3 would be a product in Z3, and §6 showed there are none.

Optional · Python

Every arrows_between call flips its arguments, and each composite comp[(proj, m)] becomes comp[(m, inj)] — the mediator is now applied after the injection:

coproducts.py
def find_coproducts(C, A, B):
    hits = []
    for P in C.obj:
        for iA in arrows_between(C, A, P):
            for iB in arrows_between(C, B, P):
                ok = True
                for X in C.obj:
                    for f in arrows_between(C, A, X):
                        for g in arrows_between(C, B, X):
                            med = [m for m in arrows_between(C, P, X)
                                   if C.comp[(m, iA)] == f
                                   and C.comp[(m, iB)] == g]
                            if len(med) != 1: ok = False
                if ok: hits.append((P, iA, iB))
    return hits

print(find_coproducts(Div, 2, 3))   # [(6, '2|6', '3|6')]  -- the lcm
print(find_coproducts(Z3, '*', '*'))  # []
output[(6, '2|6', '3|6')] []

Z3 has no coproducts either — as duality predicts. Z3 is isomorphic to its own opposite (reverse the arrows of a commutative group and relabel), so “no products in Z3op” translates directly into “no coproducts in Z3.” Exercise 15’s by-hand proof dualizes the same way, word for word.

Global elements

Going deeper · Exercise 17

Exercise 17structure

Global elements, counted in three categories:

  1. In Set, exhibit the bijection between arrows 1 → X and elements of X, and explain why two functions f, g : X → Y agreeing on all global elements must be equal.
  2. In the divisibility poset {1, 2, 3, 6} (terminal object: 6), which objects have a global element?
  3. In Grp the terminal object is the trivial group. How many global elements does a group have? Exhibit two different homomorphisms ℤ → ℤ that agree on every global element.
Show solution

(a) A function from a one-point set has exactly one value to choose, so arrows 1 → X correspond to elements x ∈ X via ∗ ↦ x. If f, g agree on every global element, then for each x, composing with the arrow picking x gives f(x) = g(x) — pointwise agreement, hence equality. Set is well-pointed: the single probe 1 suffices.

(b) A global element of x is an arrow 6 → x, which exists iff 6 | x — so only x = 6 has one. Every other object is invisible to the probe 1.

(c) A homomorphism out of the trivial group must send its one element to the identity, so every group has exactly one global element. Consequently any two homomorphisms G → H agree on global elements — for instance the identity of ℤ and the zero homomorphism n ↦ 0, which are certainly different. In Grp, arrows are not determined by global elements. One probe is nowhere near enough in general; you need them all, which is exactly the widening that generalized elements — and, in Lesson 9, the Yoneda embedding — perform.

Recap

What to carry forward

  1. A universal property defines an object by a mapping problem it solves best: for every candidate, exactly one arrow factors through it. Existence and uniqueness are separate clauses, and both carry weight.
  2. Terminal and initial objects are the smallest instances; anything universal is unique up to unique isomorphism, by a four-sentence proof that recurs throughout the subject.
  3. The product is the pair defined without elements — and the same definition yields direct products, meets, and gcds, depending on the category. Products need not exist, and whether they do is real information.
  4. Duality: reverse all arrows and every definition and theorem dualizes — coproducts (disjoint unions, joins, lcms, tagged unions) come free from products.
  5. A product is a terminal object in a category of spans — so its uniqueness is the uniqueness of terminal objects, and arrows into it are determined by their two components.
  6. In a finite category, a universal property is a finite search: it can be settled by listing the candidates, by hand or by machine — including proofs that no universal object exists.
