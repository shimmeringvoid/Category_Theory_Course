Intro to Category Theory

Objects, arrows, and the discipline of never peeking inside — with animated diagrams, full proofs, and optional Python labs in which every claim is checked.

The course

Each lesson is a self-contained page: motivation, boxed definitions and theorems with their proofs, worked examples with commutative diagrams that draw themselves, a section of computations carried out by hand, and a large set of exercises with hidden solutions — from warm-ups to arrows-only proofs. No programming is required. For readers who know Python, every lesson also has an optional lab in which the day’s concept is implemented and machine-checked (each output shown was produced by the code shown), and a few exercises carry an optional Python part. The lessons build strictly in order; start at 01.

How to use these pages

With pencil and paper. Every lesson can be read from start to finish without a computer, and the exercises are pen-and-paper problems; where one has a Python part, that part is optional. Do the exercises before opening the solutions; the arrows-only ones are the course.

With Python, if you like. The optional labs are folded away inside each lesson; the button at the top of a lesson opens or closes all of them. The same code is collected, lesson by lesson, as plain scripts in code/ and as Jupyter notebooks in notebooks/, and needs nothing beyond Python 3.

Keep all the .html files in one folder so that the links between lessons work.
